# 設計: v0.4 IR 生成（一般化した let の参照ごとの変換）・サンプル・E2E

## 目的

ADR-0006 のとおり、一般化した `let` を、その場では評価せず、名前を参照するたびに右辺をその型引数で IR に変換する。
これにより、let 多相と型注釈を省略した匿名関数を使うプログラムを `ceroc build` / `ceroc run` で実行できるようにする。

対象外にすること:

* IR のノードと値型の追加・変更（v0.3 のまま使う）
* WebAssembly バックエンドの変更
* 同じ型引数での参照どうしで、持ち上げた匿名関数を共有する最適化（ADR-0006 の Consequences）
* 一般化した `let` の参照を、関数の直接呼び出し（`ir.Call`）に変える最適化。参照は常に値（`ir.FuncValue` など）として変換し、呼び出しは `ir.CallIndirect` になる

## 関連する ADR

* ADR-0002: 値の表現、lambda lifting
* ADR-0004: 型引数の表現ごとの特殊化
* ADR-0005: 末尾呼び出し
* ADR-0006: 一般化した `let` を参照ごとに変換すること

## `internal/lower`

### 状態

```go
type lowerer struct {
	// ... v0.3 fields unchanged ...

	// polyLets maps the symbol of every generalized let to its statement.
	polyLets map[*typecheck.Symbol]*ast.LetStmt
}
```

`Lower` の最初（`lowerer` を作るところ）で、次のように `polyLets` を作る。

```text
polyLets = empty map
for stmt, sym in info.Defs:
    if len(sym.TypeParams) > 0: polyLets[sym] = stmt
```

### `let` の変換（`lowerBlock`）

```text
lowerBlock(fn, locals, e):
    if len(e.Lets) == 0: return lowerExpr(fn, locals, e.Result)        (v0.3)
    lets = make([]*ir.Let, 0, len(e.Lets))
    for stmt in e.Lets:
        sym = info.Defs[stmt]; nil → panic (v0.3 のメッセージ)
        if len(sym.TypeParams) > 0: continue          // generalized: lowered at each use
        value = lowerExpr(fn, locals, stmt.Value)
        id = LocalID(len(fn.Locals)); locals[sym] = id
        fn.Locals.append(valType(sym.Type))
        lets.append(&ir.Let{Local: id, Value: value})
    if len(lets) == 0: return lowerExpr(fn, locals, e.Result)
    return &ir.Block{Lets: lets, Result: lowerExpr(fn, locals, e.Result)}
```

* v0.3 は右辺を変換してから `Defs` のシンボルを引いていた。v0.4 では一般化しているかを先に知る必要があるので、シンボルを先に引く。
  局所変数の番号を、右辺の変換の後に割り当てる順序（`let value lowered before local is allocated`）は変えない。
* 一般化した `let` は局所変数を持たない。すべての `let` が一般化されていれば、`ir.Block` を作らずに結果の式だけを返す。

### 名前の参照（`lowerIdent`）

`lowerIdent` に `fn *ir.Func` 引数を加える（一般化した `let` の右辺を変換するのに要る）。呼び出し側（`convert`）も合わせて変える。

```go
func (l *lowerer) lowerIdent(
	fn *ir.Func,
	e *ast.Ident,
	locals map[*typecheck.Symbol]ir.LocalID,
) ir.Expr
```

`SymParam` / `SymLocal` の分岐の先頭に、一般化した `let` の処理を入れる。ほかの分岐は変えない。

```text
case SymParam, SymLocal:
    if len(sym.TypeParams) > 0:
        return l.lowerPolyUse(fn, locals, e, sym)
    ... v0.3 のまま（locals から LocalGet）...
```

```go
// lowerPolyUse lowers a use at id of the generalized let sym by lowering the
// let's value with the let's type parameters mapped to the representations
// of the use's type arguments.
func (l *lowerer) lowerPolyUse(
	fn *ir.Func,
	locals map[*typecheck.Symbol]ir.LocalID,
	id *ast.Ident,
	sym *typecheck.Symbol,
) ir.Expr
```

```text
lowerPolyUse(fn, locals, id, sym):
    stmt = l.polyLets[sym]
    if stmt == nil: panic("lower: missing let for generalized '%s' at %s", id.Name, id.Pos)
    args = l.info.TypeArgs[id]
    if len(args) != len(sym.TypeParams): panic("lower: missing type arguments for '%s' at %s", id.Name, id.Pos)
    env = new map with every entry of l.env       // l.env may be nil
    for i, tp in sym.TypeParams:
        env[tp] = l.valType(args[i])              // in the current l.env, before switching
    saved = l.env
    l.env = env
    value = l.lowerExpr(fn, locals, stmt.Value)
    l.env = saved
    return value
```

* `env` は毎回新しい map にする。`l.env` 自体を書き換えない（特殊化の `instance.env` と共有しているため）。
* 右辺は匿名関数か名前（`typecheck` の `generalizable`）なので、変換しても `fn` の局所変数は増えない。
  右辺が匿名関数なら、`lowerFuncLit` が新しい関数を持ち上げ、`l.env` の値型で引数と結果の型を決める。参照ごとに別の関数になる。
  右辺が名前なら、その名前を `lowerIdent` で変換する。多相な関数なら、その `TypeArgs`（一般化した `let` の型パラメータを含む）を `l.env` で値型に写して特殊化を選ぶ。
  一般化した別の `let` の名前なら、`lowerPolyUse` が再帰的に呼ばれる。
* 参照の式（`id`）の型の検査（`lowerExpr` の「IR の型と型検査の型の一致」）は、呼び出し側の `lowerExpr` が元の `l.env` で行う。
  右辺の式の型の検査は、`lowerPolyUse` の中の `lowerExpr` が新しい `env` で行う。

### 呼び出し（`lowerCall`）

変更しない。呼び出し対象が一般化した `let` の名前（`SymLocal`）なら、v0.3 の `ir.CallIndirect` の分岐に進み、`Callee` の変換で `lowerPolyUse` が呼ばれる。

### 匿名関数の型（`lowerFuncLit`）

変更しない。`info.FuncLits[e]` の型注釈を省略した引数と結果の型は、型検査の `resolveInfo` で解決済みである。

### generalized let inside a generic function

```text
fn twice[T](x: T) -> T { let id = fn(y) { y } id(id(x)) }
fn main() -> Int { if twice(true) { twice(1) } else { 0 } }
```

```text
(func 0 main (sig () Int) (locals) (if (call 1 true) (return.call 2 1) 0))
(func 1 twice[Bool] (sig (Bool) Bool) (locals Bool) (return.call.indirect (sig (Bool) Bool) (func.ref 3) (call.indirect (sig (Bool) Bool) (func.ref 4) (local 0))))
(func 2 twice[Int] (sig (Int) Int) (locals Int) (return.call.indirect (sig (Int) Int) (func.ref 5) (call.indirect (sig (Int) Int) (func.ref 6) (local 0))))
(func 3 lambda$0 (sig (Bool) Bool) (locals Bool) (local 0))
(func 4 lambda$1 (sig (Bool) Bool) (locals Bool) (local 0))
(func 5 lambda$2 (sig (Int) Int) (locals Int) (local 0))
(func 6 lambda$3 (sig (Int) Int) (locals Int) (local 0))

```

* 外側の `id` の参照（`Callee`）を、引数の `id(x)` より先に変換する（`ir.CallIndirect` の複合リテラルのフィールドの順）。そのため、外側の参照の匿名関数が先に番号を取る。

### generalized let of a generalized let

```text
fn identity[T](x: T) -> T { x }
fn main() -> Int { let f = identity let g = f g(5) }
```

```text
(func 0 main (sig () Int) (locals) (return.call.indirect (sig (Int) Int) (func.ref 1) 5))
(func 1 identity[Int] (sig (Int) Int) (locals Int) (local 0))
(table 1)
(main 0)
```

既存のテストはすべてそのまま通ること（既存のソースには、一般化される `let` がない）。

## E2E（`internal/driver/e2e_test.go` に追加）

| ケース | ソース | 出力 |
| --- | --- | --- |
| let-polymorphic anonymous function | `fn main() -> Int { let id = fn(x) { x } if id(true) { id(40) + 2 } else { 0 } }` | `42` |
| let-polymorphic None | 下記 | `42` |
| match infers the scrutinee type | 下記 | `42` |
| inference example | `file: "examples/inference.cero"` | `42` |

```text
// let-polymorphic None
type Option[T] = | None | Some(T)

fn orElse[T](o: Option[T], d: T) -> T { match o { None => d, Some(x) => x } }

fn main() -> Int {
    let none = None
    if orElse(none, true) { orElse(none, 41) + 1 } else { 0 }
}
```

```text
// match infers the scrutinee type
type Option[T] = | None | Some(T)

fn main() -> Int {
    let get = fn(o) { match o { Some(n) => n, None => 0 } }
    get(Some(40)) + get(None) + 2
}
```

既存の `let bound to a generic function`（`let f = identity`）は、一般化されるようになるが、出力（`6`）は変わらない。

## `examples/inference.cero`（新規）

```text
// expected output: 42

type List[T] =
    | Nil
    | Cons(T, List[T])

fn range(from: Int, to: Int) -> List[Int] {
    if from > to {
        Nil
    } else {
        Cons(from, range(from + 1, to))
    }
}

fn map[T, U](xs: List[T], f: T -> U) -> List[U] {
    match xs {
        Nil => Nil,
        Cons(x, rest) => Cons(f(x), map(rest, f)),
    }
}

fn foldl[T, A](xs: List[T], acc: A, f: (A, T) -> A) -> A {
    match xs {
        Nil => acc,
        Cons(x, rest) => foldl(rest, f(acc, x), f),
    }
}

fn main() -> Int {
    // Generalized: used at Int and at List[Bool] below.
    let id = fn(x) { x }
    let twice = fn(f, x) { f(f(x)) }

    // The parameter types come from map's and foldl's signatures.
    let xs = map(range(1, 3), fn(x) { x * 2 })
    let flags = id(map(xs, fn(x) { x > 3 }))
    let sum = foldl(xs, 0, fn(acc, x) { acc + x })
    let trues = foldl(flags, 0, fn(n, b) { if b { n + 1 } else { n } })

    twice(fn(n) { n + 10 }, id(sum)) + trues * 5
}
```

* `xs` は `[2, 4, 6]`、`flags` は `[false, true, true]`、`sum` は `12`、`trues` は `2` である。
  `twice(fn(n) { n + 10 }, 12)` は `32` なので、結果は `32 + 2 * 5 = 42` になる。
* `id` は `List[Bool]`（`Ptr`）と `Int` の 2 つの値型で使われる。`twice` は一般化される（型は `(t2 -> t2, t2) -> t2`、型パラメータは `t2`）。
* コメントは英語で書く（既存のサンプルと同じ）。ファイル先頭の `// expected output: 42` は既存のサンプルと同じ形式である。
