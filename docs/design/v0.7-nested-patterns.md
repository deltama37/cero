# 設計: v0.7 入れ子のパターン

## 目的

ADR-0009 のとおり、構築子パターンの引数に任意のパターンを書けるようにし、網羅性と到達不能なアームを usefulness で判定し、入れ子のパターンを含む `match` を IR に変換する。

対象外にすること:

* or パターン、ガード、as パターン、範囲パターン、負の整数リテラルのパターン、`let` の左辺のパターン
* 決定木による最適化
* IR のノードと WebAssembly バックエンドの変更

## 関連する ADR

* ADR-0003: パターン、網羅性、データ型のレイアウト
* ADR-0006: 照合対象の型が未解決のときの型付け
* ADR-0009: 本書の決定

## 前提

`docs/design/v0.6-closures.md` までが実装済みであること。1 つの実装単位で実装する。

## `internal/ast`

* `CtorPat` のコメントの「each element is a *VarPat or *WildcardPat」を「each element is any Pattern」に直す。
* 表示（`FormatPattern` など）はすでに再帰的なら変更しない。入れ子の表示のテストを足す（例: `Cons(x, Cons(_, Nil))`）。

## `internal/parser`

* 構築子パターンの引数を `parsePattern` で読む。`parseSubPattern` と「nested patterns are not supported in v0.2」のエラーを削除する。
* 既存のエラーケース 2 件（`parser_test.go`）は成功ケースに移す。

## `internal/typecheck`

### パターンの型付け（`checkPattern`）

```text
checkPattern(ctx, p, st, seen):          // seen: このアームのパターン全体で束縛した変数名
    st = Prune(st)
    if st is *Meta and p is CtorPat / IntPat / BoolPat:
        inferScrutinee と同じ規則で st を解く（CtorPat なら Named{ctor.Data, 新しい単一化変数}、IntPat なら Int、BoolPat なら Bool）
        st = Prune(st)
    WildcardPat: ok
    VarPat:
        if seen[name]: error "duplicate variable '%s' in pattern"
        seen[name] = true; checkBindable; bindPatVar(ctx, p, st)
    IntPat:  if !unify(st, Int):  error at p.Pos "expected %s, found Int"
    BoolPat: if !unify(st, Bool): error at p.Pos "expected %s, found Bool"
    CtorPat:
        (v0.6 と同じ: 未知の構築子、型の不一致、フィールドの個数)
        for i, arg in p.Args:
            field = Subst(ctor.Fields[i], ctor.Data.Params, named.Args)
            checkPattern(ctx, arg, field, seen)
        c.info.CtorPats[p] = ctor
```

`inferMatchArm` は、アームごとに新しい `seen` を作って `checkPattern` を呼ぶ。
既存の `coverage` 型と `covers` / `add` / `missing` は削除し、次の usefulness に置き換える。

### `inferMatch` の流れ

```text
inferMatch:
    (照合対象の型付けは v0.6 のまま)
    for each arm: 型付けして結果の型を単一化（v0.6 のまま。到達不能の検査はここでしない）
    rows = []
    for each arm:
        q = [toSpat(arm.Pattern)]
        if !useful(rows, q): error at arm.Pattern.Position() "unreachable match arm"
        rows = append(rows, q)
    if msg := missingMessage(rows); msg != "": error at m.Pos "non-exhaustive match: missing " + msg
```

### `exhaust.go`（新規）

```go
type spatKind int

const (
	spWild spatKind = iota // '_' or a variable
	spCtor
	spInt
	spBool
)

// spat is a pattern reduced to what usefulness needs.
type spat struct {
	kind spatKind
	ctor *types.Ctor // spCtor
	args []spat      // spCtor: one per field
	ival int64       // spInt
	bval bool        // spBool
}

// toSpat converts p; ctors maps constructor patterns to their constructors
// (Info.CtorPats).
func toSpat(p ast.Pattern, ctors map[*ast.CtorPat]*types.Ctor) spat

// useful reports whether some value matched by q is matched by no row of rows.
// Every row and q have the same length.
func useful(rows [][]spat, q []spat) bool

// witness returns n patterns that together match a value matched by no row
// of rows, or false when every value is matched.
func witness(rows [][]spat, n int) ([]spat, bool)

// missingMessage returns "" when the one-column rows are exhaustive, and
// otherwise the text after "missing " in ADR-0009's format.
func missingMessage(rows [][]spat) string

// formatSpat formats p in source syntax: "_", "42", "true", "Nil", "Cons(_, Nil)".
func formatSpat(p spat) string
```

用語:

* **先頭の集合 Σ**: 行列の 1 列目に現れる、ワイルドカードでない頭（構築子、整数、真偽値）の集合。
* **完全**: Σ が構築子なら、その構築子のデータ型（`ctor.Data.Ctors`）のすべての構築子を含む。真偽値なら `true` と `false` の両方を含む。整数なら常に完全でない。Σ が空なら完全でない。
* **頭の順序**: 構築子は宣言順（`Index`）、真偽値は `true`、`false` の順。
* **特殊化 S(c, rows)**: 1 列目が `c` と同じ頭の行は、その引数を先頭に並べた残りの行にする。1 列目がワイルドカードの行は、`c` の引数の数だけワイルドカードを先頭に並べる。それ以外の行は捨てる。整数と真偽値の頭は引数 0 個で、値が等しいときに同じ頭とする。
* **既定の行列 D(rows)**: 1 列目がワイルドカードの行の、残りの列。

```text
useful(rows, q):
    if len(q) == 0: return len(rows) == 0
    h = q[0]
    if h is not wild:
        return useful(S(h, rows), S(h, [q])[0])
    Σ = 先頭の集合(rows)
    if 完全(Σ):
        for c in 頭の順序で Σ の型のすべての頭:   // 真偽値は true, false
            if useful(S(c, rows), S(c, [q])[0]): return true
        return false
    return useful(D(rows), q[1:])

witness(rows, n):
    if n == 0: return [], len(rows) == 0
    Σ = 先頭の集合(rows)
    if 完全(Σ):
        for c in 頭の順序のすべての頭:
            w, ok = witness(S(c, rows), arity(c) + n - 1)
            if ok: return [c の頭に w[:arity(c)] を引数として付けたもの] ++ w[arity(c):], true
        return nil, false
    w, ok = witness(D(rows), n - 1)
    if !ok: return nil, false
    head = Σ が空なら _
           構築子なら Σ にない最初の構築子（引数はすべて _）
           真偽値なら Σ にない最初の値
           整数なら _
    return [head] ++ w, true

missingMessage(rows):
    if 1 列目にワイルドカードの行がなく、Σ が完全でない:
        Σ が構築子: Σ にないすべての構築子を宣言順に、引数をすべて _ にして formatSpat し、", " でつなぐ
        Σ が真偽値: Σ にない値を true, false の順に
        Σ が整数: "_"
        return それ
    w, ok = witness(rows, 1)
    if !ok: return ""
    return formatSpat(w[0])
```

1 列目にワイルドカードの行がなく Σ も空、という状態は `match` のアームが 1 つ以上あるので起きない。

## `internal/lower`

### 平らかどうか

```go
// flatMatch reports whether every arm's pattern has the v0.2 form: '_', a
// variable, a literal, or a constructor whose arguments are all '_' or
// variables.
func flatMatch(m *ast.MatchExpr) bool
```

`lowerMatch` は、照合対象の型が `Named` で `flatMatch` が真なら v0.6 の `lowerDataMatch` を使う。
`Named` で偽なら `lowerNestedMatch` を使う。`Int` / `Bool` の照合対象は常に平らなので v0.6 のまま。

### `lowerNestedMatch`

```text
lowerNestedMatch(fn, locals, e, s):          // s は照合対象の Ptr の局所変数
    T = valType(mustType(e))
    chain(i):
        arm = e.Arms[i]
        if i == len(e.Arms) - 1: return bindArm(fn, locals, arm, s)
        cond = patTest(fn, arm.Pattern, s, Ptr)
        if cond == nil: return bindArm(...)   // 常に一致するアーム（型検査により最後のアーム）
        return &ir.If{Cond: cond, Then: bindArm(fn, locals, arm, s), Else: chain(i + 1), T: T}
    return chain(0)

// patTest は、局所変数 x（値型 vt）の値が p に一致するかを表す Bool の式。常に一致するなら nil。
patTest(fn, p, x, vt):
    Wildcard / Var: nil
    IntPat:  Binary{Eq, LocalGet{x, Int}, IntConst}
    BoolPat: Binary{Eq, LocalGet{x, Bool}, BoolConst}
    CtorPat:
        ctor = info.CtorPats[p]
        tests = []
        if len(ctor.Data.Ctors) > 1:
            tests += SwitchTag{Local: x, Cases: [{Tag: ctor.Index, Body: BoolConst{true}}], Default: BoolConst{false}, T: Bool}
        for i, arg in p.Args:
            avt = patValType(arg); if arg is Wildcard/Var: continue
            t = 新しい局所変数（avt）
            sub = patTest(fn, arg, t, avt)
            if sub == nil: continue           // 例: 構築子が 1 つだけのデータ型で、中がすべて _ / 変数
            tests += Block{Lets: [Let{t, Field{Local: x, Index: i, T: avt}}], Result: sub}
        if tests が空: return nil
        return and(tests)                      // and(a, b, ...) = If{Cond: a, Then: and(b, ...), Else: BoolConst{false}, T: Bool}

patValType(p): CtorPat → Ptr、IntPat → Int、BoolPat → Bool（Wildcard / Var には使わない）

// bindArm は、パターンの変数をすべて局所変数に束縛してから本体を変換する。
bindArm(fn, locals, arm, s):
    lets = []
    bind(p, x):
        Var: locals[patVar(p)] = x
        CtorPat:
            for i, arg in p.Args:
                Var:     id = 新しい局所変数(valType(sym.Type)); lets += Let{id, Field{x, i, その型}}; locals[sym] = id
                CtorPat: 変数を含むときだけ id = 新しい局所変数(Ptr); lets += Let{id, Field{x, i, Ptr}}; bind(arg, id)
                それ以外: なし
        それ以外: なし
    bind(arm.Pattern, s)
    body = lowerExpr(fn, locals, arm.Body)
    return lets が空なら body、そうでなければ Block{lets, body}
```

フィールドの読み出しは、`patTest` の論理積によってタグを確かめた後でだけ評価される。
`bindArm` の読み出しは、そのアームのパターンに一致した後でだけ評価される。
末尾呼び出しの印（`markTailCalls`）は `If` の `Then` / `Else` と `Block` の `Result` をたどるので、アームの本体は末尾位置のままになる。条件の中の式は末尾位置ではない。

## エラーケースと扱い

| 条件 | 位置 | メッセージ |
| --- | --- | --- |
| 入れ子の中の変数の重複 | 2 回目の変数 | `duplicate variable 'x' in pattern` |
| 入れ子の中の型の不一致 | そのパターン | `expected Int, found Bool` など（v0.6 と同じ形式） |
| 入れ子の中の未知の構築子・フィールドの数 | そのパターン | v0.6 と同じ |
| 到達不能なアーム | アームのパターン | `unreachable match arm` |
| 網羅していない | `match` | `non-exhaustive match: missing ...`（ADR-0009） |

到達不能と網羅性の検査は、すべてのアームの型付けの後で行う（v0.6 ではアームごとに型付けの途中で行っていた）。
そのため、到達不能なアームと型エラーの両方があるプログラムでは、報告するエラーが変わることがある。

### `typecheck_test.go`

* 既存の網羅性のエラーケースのメッセージを、ADR-0009 の形式に直す（例: `non-exhaustive match: Circle, Square` → `non-exhaustive match: missing Circle(_), Square(_, _)`。フィールドの有無は各テストの型宣言に合わせる）。
* 追加（`TestCheckNestedPatternSuccess` / `TestCheckNestedPatternError`）:
  * 成功: 入れ子の構築子、入れ子のリテラル、入れ子の変数の型（`Cons(x, Cons(y, _))` の `x`、`y` が `Int`）、未解決の型を入れ子のパターンから決める（`fn(p) { match p { Some(Cons(x, _)) => x, _ => 0 } }`）、`Info.CtorPats` に入れ子の構築子パターンが記録される。
  * エラー: 上の表の各行、入れ子の到達不能（`Cons(_, _)` の後の `Cons(_, Nil)`）、入れ子の網羅性（`missing Cons(_, Cons(_, _))`）、型パラメータの値を入れ子でリテラルと照合する（`Some(1)` を `Option[T]` に → `expected T, found Int`）。

### `parser_test.go` / `print_test.go`

* `Cons(x, Cons(_, Nil))`、`Pair(true, 0)`、`Some(Some(x))` の構文解析と表示。

### `lower_test.go`

* 平らなパターンだけの `match` の IR が変わらない（既存のゴールデンがそのまま通る）。
