# 設計: v0.1 WebAssembly バックエンド・コンパイルドライバ・CLI

## 目的

IR（`docs/design/v0.1-ir.md`）から WebAssembly バイナリ（`.wasm`）を生成し、`ceroc build` と `ceroc run` で使えるようにする。
これにより ADR-0001 の Initial Goal（`fib(10)` のコンパイルとローカル実行）を達成する。

対象外にすること:

* WAT（テキスト形式）の出力
* WASI、import、メモリ
* `ceroc fmt`（引き続き未実装のまま）
* WebAssembly ランタイムの同梱（外部コマンド `wasmtime` を使う。ADR-0002）

## 関連する ADR

* ADR-0001: コンパイル先、実行環境、エントリポイント、エラー形式
* ADR-0002: WebAssembly ABI、`ceroc run` のランタイム

## 前提

フロントエンド、型検査、IR の設計書の内容が実装済みであること。

### 値型

| IR | wasm | バイト |
| --- | --- | --- |
| `ir.Int` | `i64` | `0x7E` |
| `ir.Bool` | `i32` | `0x7F` |
| `ir.FuncRef` | `i32` | `0x7F` |

### モジュールの構成

ヘッダ `00 61 73 6D 01 00 00 00` の後に、次のセクションをこの順で出力する。
各セクションは「ID 1 バイト、内容のバイト数（uleb128）、内容」の形とする。ベクタは「要素数（uleb128）、要素...」の形とする。

1. Type（ID 1）: 関数型のベクタ。各要素は `0x60`、引数の値型のベクタ、結果の値型のベクタ（要素数 1）。
2. Function（ID 3）: 各 `ir.Func` の型インデックスのベクタ（`Module.Funcs` の順）。
3. Table（ID 4）: テーブル 1 個。`0x70`（funcref）、limits `0x01 min max`（min = max = `len(Module.Table)`）。
   テーブルが空でも必ず出力する（`call_indirect` はテーブルがないと検証エラーになるため）。
4. Export（ID 7）: エクスポート 1 個。名前 `main`（長さ uleb128 + UTF-8 バイト列）、`0x00`（関数）、`Module.Main` の関数インデックス。
5. Element（ID 9）: `len(Module.Table) > 0` のときだけ出力する。セグメント 1 個で、フラグ `0x00`、オフセット式 `41 00 0B`（`i32.const 0; end`）、`Module.Table` の関数インデックスのベクタ。
6. Code（ID 10）: 関数本体のベクタ（`Module.Funcs` の順）。各本体は「本体のバイト数（uleb128）、ローカル宣言、命令列、`0x0B`」。

関数インデックスは `FuncID` をそのまま使う（import がないため）。

### 型インデックス

関数型を wasm の値型の列（引数の列と結果）で重複排除し、最初に現れた順に番号を付ける。走査順は次のとおり。

1. `Module.Funcs` の順に、各関数の `Sig`
2. `Module.Funcs` の順に、各関数の本体を前順（ノード自身 → 子を左から）で走査し、現れた `CallIndirect` の `Sig`

`Bool` と `FuncRef` はどちらも `i32` なので、`(sig (Bool) Int)` と `(sig (FuncRef) Int)` は同じ型インデックスになる。

### ローカル宣言

引数以外のローカル（`Locals[len(Sig.Params):]`）を、wasm の値型が同じものが連続する区間ごとに `(個数 uleb128, 値型)` にまとめ、そのベクタを出力する。ローカルがなければ `0x00`。

### 命令の生成

| IR | 命令 |
| --- | --- |
| `IntConst` | `i64.const v`（`0x42` + sleb128） |
| `BoolConst` | `i32.const 0/1`（`0x41 0x00` / `0x41 0x01`） |
| `LocalGet` | `local.get n`（`0x20` + uleb128） |
| `FuncValue` | `i32.const k`（`0x41` + sleb128）。k は `Module.Table` 内での位置 |
| `Unary Neg` | `i64.const 0`、X、`i64.sub` |
| `Unary Not` | X、`i32.eqz`（`0x45`） |
| `Binary`（X が `Int`） | X、Y、下表の命令 |
| `Binary Eq/Ne`（X が `Bool`） | X、Y、`i32.eq`（`0x46`）/ `i32.ne`（`0x47`） |
| `If` | Cond、`if`（`0x04` + 結果の値型）、Then、`else`（`0x05`）、Else、`end`（`0x0B`） |
| `Block` | 各 `Let` について Value、`local.set n`（`0x21` + uleb128）。最後に Result |
| `Call` | 引数を左から、`call f`（`0x10` + uleb128） |
| `CallIndirect` | 引数を左から、Callee、`call_indirect t 0`（`0x11` + 型インデックス uleb128 + `0x00`） |

`Int` の二項演算:

| BinOp | 命令 | バイト |
| --- | --- | --- |
| `Add` | `i64.add` | `0x7C` |
| `Sub` | `i64.sub` | `0x7D` |
| `Mul` | `i64.mul` | `0x7E` |
| `Div` | `i64.div_s` | `0x7F` |
| `Eq` | `i64.eq` | `0x51` |
| `Ne` | `i64.ne` | `0x52` |
| `Lt` | `i64.lt_s` | `0x53` |
| `Gt` | `i64.gt_s` | `0x55` |
| `Le` | `i64.le_s` | `0x57` |
| `Ge` | `i64.ge_s` | `0x59` |

想定外の IR（`FuncRef` 同士の `Eq` など）は `panic` とする。

## `internal/driver`

```go
package driver

// Compile runs the whole pipeline (parse, type check, lower, encode) on src.
// Compile errors are returned as *diag.Error with File set to filename.
func Compile(filename string, src []byte) ([]byte, error)
```

```text
Compile(filename, src):
    file, err = parser.ParseFile(src);  if err: return nil, withFile(err)
    info, err = typecheck.Check(file);  if err: return nil, withFile(err)
    return wasm.Encode(lower.Lower(file, info)), nil

withFile(err):
    var d *diag.Error
    if errors.As(err, &d): copy := *d; copy.File = filename; return &copy
    return err
```

公開 API は変えない。


終了コード:

```go
const (
	exitOK             = 0
	exitFailure        = 1 // compile error, I/O error, runtime failure
	exitUsageError     = 2
	exitNotImplemented = 3
)
```

使い方の表示（`usage`）の `Commands:` を次に変える。

```text
    build      Compile a Cero source file to WebAssembly
    run        Compile and run a Cero source file with wasmtime
    fmt        Format Cero source code (not yet implemented)
    version    Print the ceroc version
    help       Print this help message
```

`Usage:` の下に次の 2 行を追加する。

```text
    ceroc build [-o output.wasm] <file.cero>
    ceroc run <file.cero>
```

### `ceroc build`

```text
build(args):
    input, output, err = parseBuildArgs(args)
    if err: print "ceroc build: " + err to stderr; return exitUsageError
    if output == "": output = defaultOutput(input)
    src, err = os.ReadFile(input)
    if err: print "ceroc: read INPUT: ERR" ; return exitFailure
    wasm, err = driver.Compile(input, src)
    if err: print err (one line) to stderr; return exitFailure
    err = os.WriteFile(output, wasm, 0o644)
    if err: print "ceroc: write OUTPUT: ERR"; return exitFailure
    return exitOK   // prints nothing on success
```

* `parseBuildArgs`: 引数を左から見る。
  * `-o` の次の引数を出力パスにする。次がなければ `-o requires an argument`。
  * `-o` 以外で `-` から始まる引数は `unknown flag "-x"`。
  * それ以外は入力ファイル。2 個目が来たら `too many arguments`。
  * 最後まで入力ファイルがなければ `missing input file`。
  * `-o` と入力ファイルの順序は問わない。
* `defaultOutput`: `.cero` で終われば、それを `.wasm` に置き換える。そうでなければ末尾に `.wasm` を付ける。
* 読み書きのエラーは `fmt.Errorf("read %s: %w", ...)` のようにラップして、`ceroc: ` を付けて表示する。

### `ceroc run`

```text
run(args):
    input, err = parseRunArgs(args)  // exactly one non-flag argument; same messages as build
    if err: print "ceroc run: " + err; return exitUsageError
    runtime = getenv("CERO_WASM_RUNTIME"); if runtime == "": runtime = "wasmtime"
    path, err = exec.LookPath(runtime)
    if err: print `ceroc run: WebAssembly runtime "RUNTIME" not found (install wasmtime or set CERO_WASM_RUNTIME)`; return exitFailure
    read + compile as in build (same error handling)
    dir = os.MkdirTemp("", "ceroc-run-*"); defer os.RemoveAll(dir)
    write DIR/main.wasm
    cmd = exec.Command(path, "run", "--invoke", "main", DIR/main.wasm)
    cmd.Stdout = stdout; cmd.Stderr = buffer
    if cmd.Run() fails:
        write buffer contents to stderr
        print "ceroc run: runtime failed: ERR"
        return exitFailure
    return exitOK   // runtime stderr (e.g. wasmtime's --invoke warning) is discarded on success
```

`parseRunArgs` の規則は `parseBuildArgs` から `-o` を除いたものとする（`-` で始まる引数はすべて `unknown flag`）。

## サンプル（`examples/`）

`examples/fib.cero`（ADR-0001 の Initial Goal そのもの）:

```text
fn fib(n: Int) -> Int {
    if n <= 1 {
        n
    } else {
        fib(n - 1) + fib(n - 2)
    }
}

fn main() -> Int {
    fib(10)
}
```

`examples/higher_order.cero`: 匿名関数、関数を引数に取る関数、関数を返す関数、`let`、シャドーイングを使い、`main` が `42` を返すプログラム。先頭のコメントに期待する出力 `42` を書く。

## テスト観点

テーブル駆動。各テストとサブテストで `t.Parallel()`。

### `wasm`

* `appendUleb128`: `0` → `00`、`127` → `7F`、`128` → `80 01`、`624485` → `E5 8E 26`
* `appendSleb128`: `0` → `00`、`-1` → `7F`、`63` → `3F`、`64` → `C0 00`、`-64` → `40`、`-65` → `BF 7F`、`math.MaxInt64`、`math.MinInt64`
* ゴールデン: `fn main() -> Int { 42 }` を IR にして `Encode` した結果が次と完全一致する。

```text
00 61 73 6D 01 00 00 00
01 05 01 60 00 01 7E
03 02 01 00
04 05 01 70 01 00 00
07 08 01 04 6D 61 69 6E 00 00
0A 06 01 04 00 42 2A 0B
```

* 型の重複排除: 同じ `Sig` の関数が 2 つで Type セクションの要素数が 1。`(sig (Bool) Int)` と `(sig (FuncRef) Int)` が同じ型になる。
* テーブルが空でないとき Element セクションが出力され、空のときは出力されない。
* ローカル宣言のまとめ方（`Int Int Bool Int` → `03 02 7E 01 7F 01 7E`）

### `driver`

* 構文エラーと型エラーが `*diag.Error` で、`File` が設定され、`Error()` が `main.cero:L:C: ...` になる。
* 正しいプログラムでエラーなくバイト列（`\0asm` で始まる）が返る。

### `cli`

既存の `TestRun` のテーブルに追加する。ファイルを使うケースは `t.TempDir()` にソースを書く。

* `build` 成功: 既定の出力パス（`x.cero` → `x.wasm`）にファイルができ、`\0asm` で始まる
* `build -o out.wasm x.cero` と `build x.cero -o out.wasm`
* `build` の使い方エラー: 引数なし、`-o` の値なし、未知のフラグ、入力が 2 個 → 終了コード 2 とメッセージ
* `build` のコンパイルエラー: 終了コード 1、標準エラーに `PATH:L:C: msg`
* `build` の読み込みエラー（存在しないファイル）: 終了コード 1、`ceroc: read`
* `run` の使い方エラー
* `run` でランタイムが見つからない: `getenv` が `CERO_WASM_RUNTIME` に存在しないパスを返す → 終了コード 1、`not found`
* `run` 成功（`wasmtime` がなければ `t.Skip`）: `examples/fib.cero` 相当のソースで標準出力が `55\n`
* `run` の実行時エラー（`wasmtime` がなければ `t.Skip`）: `main` が `1 / 0` → 終了コード 1、`runtime failed`
* `fmt` は引き続き終了コード 3
