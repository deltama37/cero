# 設計: v0.1 フロントエンド（診断・字句解析・AST・構文解析）

## 目的

Cero v0.1 のソースコードを AST に変換する。

対象外にすること:

* エラー回復（最初のエラーで止まる）
* フォーマッタ（`ceroc fmt`）用のコメント保持
* v0.1 に含めない構文（`type`、`match`、ジェネリクス、トップレベル `let` など）

## 関連する ADR

* ADR-0001: 言語機能とコンパイルエラーの形式
* ADR-0002: 具体構文とエラー報告の方針

## `internal/diag`

```go
package diag

// Pos is a 1-based source position. Col counts Unicode code points.
type Pos struct {
	Line int
	Col  int
}

// String returns "line:col".
func (p Pos) String() string

// Error is a compile error at a source position.
// File is empty until the driver fills it in.
type Error struct {
	File string
	Pos  Pos
	Msg  string
}

// Error returns "file:line:col: msg", or "line:col: msg" when File is empty.
func (e *Error) Error() string

// Errorf builds an *Error with an empty File.
func Errorf(pos Pos, format string, args ...any) *Error
```

各フェーズの関数は、エラー時に `*diag.Error` を `error` として返す（ラップしない）。

## `internal/token`

```go
package token

type Kind int

const (
	EOF Kind = iota
	Ident  // foo
	Int    // 123

	// Keywords
	Fn    // fn
	Let   // let
	If    // if
	Else  // else
	True  // true
	False // false

	// Punctuation
	LParen // (
	RParen // )
	LBrace // {
	RBrace // }
	Comma  // ,
	Colon  // :
	Arrow  // ->
	Assign // =

	// Operators
	Plus   // +
	Minus  // -
	Star   // *
	Slash  // /
	Eq     // ==
	NotEq  // !=
	Lt     // <
	LtEq   // <=
	Gt     // >
	GtEq   // >=
	AndAnd // &&
	OrOr   // ||
	Bang   // !
)

// String returns the name used in error messages:
//   EOF    -> "end of file"
//   Ident  -> "identifier"
//   Int    -> "integer literal"
//   others -> the source text in single quotes, e.g. "'fn'", "'('", "'->'", "'&&'"
func (k Kind) String() string

// Keywords maps keyword spellings to their kinds ("fn" -> Fn, ...).
var Keywords map[string]Kind

type Token struct {
	Kind Kind
	Text string   // source text; "" for EOF
	Pos  diag.Pos // position of the first character
}
```

## `internal/lexer`

```go
package lexer

// Tokenize splits src into tokens. The last token is always EOF, positioned
// just after the last character (line/col of the next character that would appear).
func Tokenize(src []byte) ([]token.Token, error)
```

### 規則

* 最初に `utf8.Valid(src)` を確認する。不正なら位置 `1:1` で `invalid UTF-8 encoding` を返す。
* 空白: `' '`、`'\t'`、`'\r'`、`'\n'` を読み飛ばす。`'\n'` で行を 1 増やし、列を 1 に戻す。その他の文字（`'\t'` を含む）は列を 1 進める。
* コメント: `//` から行末（`'\n'` の直前）まで読み飛ばす。
* 識別子: `[A-Za-z_][A-Za-z0-9_]*`。`token.Keywords` に含まれれば、そのキーワードの種類にする。
* 整数リテラル: `[0-9]+`。
  * 直後に `[A-Za-z0-9_]` が続く場合は、その連続部分全体（例: `12abc`）を Text として `invalid integer literal "12abc"` を返す。位置は先頭の数字。
  * `strconv.ParseInt(text, 10, 64)` が失敗したら `integer literal out of range: 9223372036854775808` を返す。
  * 先頭の `0` は許す（`007` は 7）。
* 記号: 2 文字の記号（`->`、`==`、`!=`、`<=`、`>=`、`&&`、`||`）を 1 文字の記号より優先して読む。
* それ以外の文字: `unexpected character '#'`（`fmt.Sprintf("unexpected character %q", r)`、`r` は rune）。
  単独の `&` と `|` もこれに当たる。

### 処理の流れ

```text
if !utf8.Valid(src): error 1:1 "invalid UTF-8 encoding"
line, col = 1, 1
loop over runes:
    skip whitespace / comments, updating line/col
    start = (line, col)
    if ident start: read ident chars; kind = Keywords[text] or Ident
    else if digit: read digits; check trailing ident chars; ParseInt
    else: match 2-char symbols, then 1-char symbols, else error
    append Token{kind, text, start}
append Token{EOF, "", (line, col)}
```

## `internal/ast`

すべてのノードは `Pos`（ノードの先頭位置）を持つ。

```go
package ast

type File struct {
	Funcs []*FuncDecl
}

type FuncDecl struct {
	Pos     diag.Pos // 'fn'
	Name    string
	NamePos diag.Pos
	Params  []*Param
	Result  TypeExpr
	Body    *BlockExpr
}

type Param struct {
	Pos  diag.Pos // name
	Name string
	Type TypeExpr
}

// TypeExpr is a type written in source.
type TypeExpr interface {
	Position() diag.Pos
	typeExpr()
}

type NamedType struct {
	Pos  diag.Pos
	Name string // "Int", "Bool", or an unknown name (rejected by the type checker)
}

type FuncType struct {
	Pos    diag.Pos // first token of the type
	Params []TypeExpr
	Result TypeExpr
}

type Expr interface {
	Position() diag.Pos
	expr()
}

type IntLit struct {
	Pos   diag.Pos
	Value int64
}

type BoolLit struct {
	Pos   diag.Pos
	Value bool
}

type Ident struct {
	Pos  diag.Pos
	Name string
}

type UnaryExpr struct {
	Pos diag.Pos   // operator
	Op  token.Kind // token.Minus or token.Bang
	X   Expr
}

type BinaryExpr struct {
	Pos   diag.Pos   // X.Position()
	OpPos diag.Pos
	Op    token.Kind // Plus, Minus, Star, Slash, Eq, NotEq, Lt, LtEq, Gt, GtEq, AndAnd, OrOr
	X, Y  Expr
}

type CallExpr struct {
	Pos    diag.Pos // Fn.Position()
	Fn     Expr
	LParen diag.Pos
	Args   []Expr
}

type IfExpr struct {
	Pos  diag.Pos // 'if'
	Cond Expr
	Then *BlockExpr
	Else Expr // *BlockExpr or *IfExpr
}

type BlockExpr struct {
	Pos    diag.Pos // '{'
	Lets   []*LetStmt
	Result Expr
}

type LetStmt struct {
	Pos     diag.Pos // 'let'
	Name    string
	NamePos diag.Pos
	Type    TypeExpr // nil when omitted
	Value   Expr
}

type FuncLit struct {
	Pos    diag.Pos // 'fn'
	Params []*Param
	Result TypeExpr
	Body   *BlockExpr
}
```

各ノード型は `Position() diag.Pos`（`Pos` を返す）と、マーカーメソッド `expr()` / `typeExpr()` を実装する。
すべてポインタレシーバとする（`*IntLit` などが `Expr` を実装する）。

### S 式表示（`print.go`）

テストで AST を比較するための表示。

```go
func FormatFile(f *File) string      // 関数ごとに FormatFunc を "\n" で連結
func FormatFunc(d *FuncDecl) string
func FormatExpr(e Expr) string
func FormatType(t TypeExpr) string
```

| ノード | 形式 | 例 |
| --- | --- | --- |
| `NamedType` | 名前 | `Int` |
| `FuncType` | `(-> (P...) R)` | `(-> (Int Int) Bool)`、`(-> () Int)` |
| `IntLit` | 10 進数 | `42` |
| `BoolLit` | `true` / `false` | `true` |
| `Ident` | 名前 | `x` |
| `UnaryExpr` | `(neg X)` / `(not X)` | `(neg x)` |
| `BinaryExpr` | `(OP X Y)`。OP はソース表記 | `(+ a (* b c))`、`(&& a b)` |
| `CallExpr` | `(call F A...)` | `(call f 1 2)`、`(call f)` |
| `IfExpr` | `(if C THEN ELSE)` | `(if c (block 1) (block 2))` |
| `BlockExpr` | `(block LET... RESULT)` | `(block (let x 1) x)` |
| `LetStmt` | `(let NAME VALUE)` / `(let NAME : TYPE VALUE)` | `(let x : Int 1)` |
| `FuncLit` | `(fn (PARAM...) RESULT BODY)` | `(fn ((x Int)) Int (block x))` |
| `Param` | `(NAME TYPE)` | `(x Int)` |
| `FuncDecl` | `(fn NAME (PARAM...) RESULT BODY)` | `(fn add ((a Int) (b Int)) Int (block (+ a b)))` |

要素の区切りは半角スペース 1 個とする。`()` は空リスト。

## `internal/parser`

```go
package parser

// ParseFile tokenizes and parses a whole Cero source file.
func ParseFile(src []byte) (*ast.File, error)

// ParseExpr parses a single expression that must span the whole input.
// Used by tests.
func ParseExpr(src []byte) (ast.Expr, error)
```

内部は再帰下降パーサ（`type parser struct { toks []token.Token; pos int }`）とする。字句エラーはそのまま返す。

### 文法

```text
file      = { funcDecl } EOF
funcDecl  = "fn" IDENT "(" [ params ] ")" "->" type block
params    = param { "," param }
param     = IDENT ":" type
type      = typeAtom [ "->" type ]
typeAtom  = IDENT
          | "(" ")"                         -- must be followed by "->"
          | "(" type ")"                    -- grouping, or a 1-param list when followed by "->"
          | "(" type "," type { "," type } ")"  -- must be followed by "->"
block     = "{" { letStmt } expr "}"
letStmt   = "let" IDENT [ ":" type ] "=" expr
expr      = or
or        = and { "||" and }
and       = eq  { "&&" eq }
eq        = rel { ( "==" | "!=" ) rel }
rel       = add { ( "<" | "<=" | ">" | ">=" ) add }
add       = mul { ( "+" | "-" ) mul }
mul       = unary { ( "*" | "/" ) unary }
unary     = ( "-" | "!" ) unary | postfix
postfix   = primary { "(" [ expr { "," expr } ] ")" }
primary   = INT | "true" | "false" | IDENT | "(" expr ")"
          | ifExpr | block | funcLit
ifExpr    = "if" expr block "else" ( block | ifExpr )
funcLit   = "fn" "(" [ params ] ")" "->" type block
```

末尾カンマは許さない。

### 型の構文解析

```text
parseType():
    start = cur.Pos
    if cur is IDENT:
        atom = NamedType; list = nil
    else if cur is "(":
        advance
        if cur is ")": advance; list = []  ; atom = nil
        else:
            first = parseType()
            if cur is ",": list = [first, parseType() for each ","] ; expect ")"
            else: expect ")"; atom = first; list = [first]
    else: error "expected type, found X"
    if cur is "->":
        advance; result = parseType()
        return FuncType{Pos: start, Params: list or [atom], Result: result}
    if atom == nil (i.e. "()" or a list of 2+): error at cur "expected '->', found X"
    return atom
```

`(Int)` は `Int` と同じ（`NamedType` を返し、その `Pos` は `Int` の位置）。`(Int) -> Int` と `Int -> Int` は同じ `FuncType` になる。

### エラーメッセージ

`found` 側の表記 `describe(tok)`:

* `Ident`: `identifier "foo"`
* `Int`: `integer literal 42`
* それ以外: `tok.Kind.String()`（`'+'`、`end of file` など）

| 状況 | メッセージ | 位置 |
| --- | --- | --- |
| 期待したトークンと違う | `expected K, found D`（K は `Kind.String()`） | 現在のトークン |
| トップレベルが `fn` 以外 | `expected 'fn', found D` | 現在のトークン |
| 式が始まらない | `expected expression, found D` | 現在のトークン |
| 型が始まらない | `expected type, found D` | 現在のトークン |
| ブロック末尾で `}` の代わりに `=` | `cannot assign: values are immutable` | `=` |
| `ParseExpr` で式の後に余りがある | `expected end of file, found D` | 現在のトークン |

`if` に `else` がない場合は `expected 'else', found D` になる。ブロックに最後の式がない場合（`{ let x = 1 }`）は `expected expression, found '}'` になる。

整数リテラルの値は `strconv.ParseInt` で得る（字句解析で範囲は検査済み）。

## テスト観点

すべてテーブル駆動で、各テストとサブテストで `t.Parallel()` を呼ぶ。

### `diag`

* `Pos{3, 7}.String()` が `3:7`
* `File` ありの `Error()` が `main.cero:4:12: expected Int, found Bool`
* `File` なしの `Error()` が `4:12: msg`

### `token`

* `Kind.String()`: `EOF`、`Ident`、`Int`、`Fn`、`Arrow`、`AndAnd` の表記

### `lexer`

トークン列を `Kind` と `Text` と `Pos` で比較する。

* 空入力 → `[EOF@1:1]`
* キーワードと識別子: `fn let if else true false foo _bar x1`
* 整数: `0 42 007 9223372036854775807`
* 全記号: `( ) { } , : -> = + - * / == != < <= > >= && || !`
* `a->b` が `a`、`->`、`b` になる。`a-b` と `a- >b` の区別
* 位置: 複数行、タブ、コメント行の後の位置、マルチバイト文字を含むコメントの後の列
* コメントのみの入力 → `EOF` の位置が最終行の次の列
* エラー: `#` → `1:1: unexpected character '#'`、`a & b` → `1:3: unexpected character '&'`、`あ` → `unexpected character 'あ'`
* エラー: `9223372036854775808` → `integer literal out of range: 9223372036854775808`
* エラー: `12abc` → `invalid integer literal "12abc"`
* エラー: 不正な UTF-8（`[]byte{0xff}`）→ `1:1: invalid UTF-8 encoding`

### `ast`

* `FormatExpr` / `FormatType` / `FormatFunc` を手組みの AST で確認する（表の各行）。

### `parser`

`ParseExpr` と `ast.FormatExpr` を使う。

* 優先順位: `1 + 2 * 3` → `(+ 1 (* 2 3))`、`a || b && c` → `(|| a (&& b c))`、`a == b < c` → `(== a (< b c))`、`a && b == c` → `(&& a (== b c))`
* 左結合: `1 - 2 - 3` → `(- (- 1 2) 3)`、`a / b * c`
* 単項: `-x * y` → `(* (neg x) y)`、`!!a` → `(not (not a))`、`- -1`
* 括弧: `(1 + 2) * 3`
* 呼び出し: `f()`、`f(1, x + 2)`、`f(1)(2)` → `(call (call f 1) 2)`、`-f(x)` → `(neg (call f x))`
* if: `if a { 1 } else { 2 }`、`else if` の連鎖、条件に比較式
* ブロック: `{ let x = 1 let y: Int = x + 1 y }`、ネストしたブロック、シャドーイング `{ let x = 1 let x = 2 x }`
* 匿名関数: `fn(x: Int) -> Int { x * 2 }`、引数なし、関数型の引数
* 改行をまたぐ式: `let value =\n if c {\n 10 } else { 20 }` を含むブロック

`ParseFile` と `ast.FormatFile` を使う。

* ADR-0001 の `add`、`abs`、`fib` + `main`、`calc`、`apply` の各例
* 関数型: `f: Int -> Int` → `(f (-> (Int) Int))`、`(Int, Int) -> Int`、`() -> Int`、`(Int -> Int) -> Int` → `(-> ((-> (Int) Int)) Int)`、`Int -> Int -> Int` → `(-> (Int) (-> (Int) Int))`、`(Int) -> Int` → `(-> (Int) Int)`、`(Int)` → `Int`
* コメントを含むファイル
* 空ファイル → 関数 0 個

エラー（メッセージと位置を完全一致で比較）:

* `fn main() -> Int { let x = 10 x = 20 x }` → `cannot assign: values are immutable`（`=` の位置）
* `fn f() -> Int { if true { 1 } }` → `expected 'else', found '}'`
* `fn f() -> Int { let x = 1 }` → `expected expression, found '}'`
* `fn f( -> Int { 1 }` → `expected ')', found '->'`
* `let x = 1` （トップレベル）→ `expected 'fn', found 'let'`
* `fn f() -> { 1 }` → `expected type, found '{'`
* `fn f(x: (Int, Int)) -> Int { 1 }` → `expected '->', found ')'`
* `fn f() -> Int { 1 + }` → `expected expression, found '}'`
* `fn f() -> Int { f(1,) }` → `expected expression, found ')'`
* `fn 1() -> Int { 1 }` → `expected identifier, found integer literal 1`
* `fn f() -> Int { 1 } }` → `expected 'fn', found '}'`
* 字句エラーがそのまま返ること（`fn f() -> Int { # }`）

* 既存の `internal/cli` は変更しない。
