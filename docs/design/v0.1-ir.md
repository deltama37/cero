# 設計: v0.1 中間表現（IR）と IR 生成

## 目的

型検査済みの AST を、実行先に依存しない独自の中間表現に変換する（ADR-0001「中間表現」）。

IR は次の性質を持つ。

* 名前はすべて解決済みで、スコープを持たない（ローカル変数は関数内の番号で表す）。
* 匿名関数はトップレベル関数に持ち上げられている（lambda lifting）。
* `&&` と `||` は `if` に展開されている。
* 型は IR の値型（`Int`、`Bool`、`FuncRef`）で表す。
* 関数値を作る箇所と、関数値を間接的に呼ぶ箇所が明示されている。

WebAssembly はスタックマシンだが構造化制御フローを持つので、v0.1 の IR は木構造の式とする。

対象外にすること:

* 最適化
* SSA、基本ブロック、制御フローグラフ
* クロージャ（環境の捕捉）

## 関連する ADR

* ADR-0001: 中間表現を挟む理由
* ADR-0002: 関数値の表現、lambda lifting、短絡評価

## 前提

`docs/design/v0.1-frontend.md` と `docs/design/v0.1-typecheck.md` の内容が実装済みであること。

## `internal/ir`

```go
package ir

type ValType int

const (
	Int     ValType = iota // 64-bit signed integer
	Bool                   // boolean
	FuncRef                // reference to a function (see Module.Table)
)

// String returns "Int", "Bool" or "FuncRef".
func (t ValType) String() string

type Sig struct {
	Params []ValType
	Result ValType
}

type FuncID int  // index into Module.Funcs
type LocalID int // index into Func.Locals

type Module struct {
	Funcs []*Func
	// Table lists every function used as a value, without duplicates,
	// in order of first use. A FuncRef value is an index into Table.
	Table []FuncID
	Main  FuncID
}

type Func struct {
	Name string // declared name, or "lambda$N" for the N-th (0-based) lifted anonymous function
	Sig  Sig
	// Locals holds the type of every local. The first len(Sig.Params)
	// entries are the parameters.
	Locals []ValType
	Body   Expr
}

type Expr interface {
	Type() ValType
	isExpr()
}

type IntConst struct{ Value int64 }
type BoolConst struct{ Value bool }

type LocalGet struct {
	Local LocalID
	T     ValType
}

// FuncValue produces a FuncRef value for Func. Func must appear in Module.Table.
type FuncValue struct{ Func FuncID }

type UnOp int

const (
	Neg UnOp = iota // Int -> Int
	Not             // Bool -> Bool
)

type Unary struct {
	Op UnOp
	X  Expr
}

type BinOp int

const (
	Add BinOp = iota // Int, Int -> Int
	Sub
	Mul
	Div
	Eq // Int, Int -> Bool  or  Bool, Bool -> Bool
	Ne
	Lt // Int, Int -> Bool
	Le
	Gt
	Ge
)

type Binary struct {
	Op   BinOp
	X, Y Expr
}

type If struct {
	Cond       Expr
	Then, Else Expr
	T          ValType
}

// Let evaluates Value and stores it into Local.
type Let struct {
	Local LocalID
	Value Expr
}

// Block runs Lets in order and yields Result.
type Block struct {
	Lets   []*Let
	Result Expr
}

// Call calls a function directly.
type Call struct {
	Func FuncID
	Args []Expr
	T    ValType
}

// CallIndirect calls the FuncRef value Callee, whose signature is Sig.
type CallIndirect struct {
	Callee Expr
	Sig    Sig
	Args   []Expr
}
```

`Type()`:

| ノード | 型 |
| --- | --- |
| `IntConst` | `Int` |
| `BoolConst` | `Bool` |
| `LocalGet` | `T` |
| `FuncValue` | `FuncRef` |
| `Unary` | `Neg` → `Int`、`Not` → `Bool` |
| `Binary` | `Add Sub Mul Div` → `Int`、それ以外 → `Bool` |
| `If` | `T` |
| `Block` | `Result.Type()` |
| `Call` | `T` |
| `CallIndirect` | `Sig.Result` |

すべてのノードはポインタ（`*IntConst` など）で `Expr` を実装する。`Let` は `Expr` ではない。

### テキスト表示（`print.go`）

```go
func Format(m *Module) string
func FormatExpr(e Expr) string
func FormatSig(s Sig) string
```

`Format` は次の行を `"\n"` で連結する（末尾の改行なし）。

1. 関数ごとに 1 行: `(func ID NAME SIG (locals T...) BODY)`
2. `(table ID...)`（空なら `(table)`）
3. `(main ID)`

`FormatSig`: `(sig (P...) R)`。例: `(sig (Int Int) Int)`、`(sig () Int)`。

| ノード | 形式 |
| --- | --- |
| `IntConst` | 10 進数（負数は `-5`） |
| `BoolConst` | `true` / `false` |
| `LocalGet` | `(local N)` |
| `FuncValue` | `(func.ref ID)` |
| `Unary` | `(neg X)` / `(not X)` |
| `Binary` | `(add X Y)`。演算子名は `add sub mul div eq ne lt le gt ge` |
| `If` | `(if C THEN ELSE)` |
| `Block` | `(block (let N VALUE)... RESULT)` |
| `Call` | `(call ID ARG...)` |
| `CallIndirect` | `(call.indirect SIG CALLEE ARG...)` |

例（`fn add(a: Int, b: Int) -> Int { a + b }` が関数 0 のとき）:

```text
(func 0 add (sig (Int Int) Int) (locals Int Int) (add (local 0) (local 1)))
```

## `internal/lower`

```go
package lower

// Lower converts a type-checked file into an IR module.
// It panics if info is inconsistent with file (a type checker bug).
func Lower(file *ast.File, info *typecheck.Info) *ir.Module
```

### 型の変換

`types.Int` → `ir.Int`、`types.Bool` → `ir.Bool`、`*types.Func` → `ir.FuncRef`。
`*types.Func` から `ir.Sig` への変換は、引数と結果それぞれに上の変換を適用する。

### 関数 ID の割り当て

1. `file.Funcs` の i 番目の `FuncDecl` に `FuncID(i)` を割り当てる。まず全関数の `ir.Func`（`Name` と `Sig` のみ）を作って `Module.Funcs` に並べる。
2. その後、`FuncDecl` を宣言順に 1 つずつ本体まで変換する。
3. 変換中に `FuncLit` に出会ったら、その時点で新しい `ir.Func` を `Module.Funcs` の末尾に追加して ID を割り当て（名前は `lambda$0`、`lambda$1`、…）、続けてその本体を変換する。匿名関数の中の匿名関数も同じ規則に従う。

`Module.Main` は `main` という名前の `FuncDecl` の ID とする。

### ローカル変数の割り当て

関数（`FuncDecl` と持ち上げた `FuncLit`）ごとに、`map[*typecheck.Symbol]ir.LocalID` を持つ。

* 引数は宣言順に `LocalID(0)` から割り当てる。
* `LetStmt` は、変換中に出会った順に次の番号を割り当てる（`Locals` の末尾に型を追加する）。値の式を変換してから番号を割り当てる。
* シャドーイングした `let` も別の番号になる。

### 式の変換

| AST | IR |
| --- | --- |
| `IntLit` | `IntConst` |
| `BoolLit` | `BoolConst` |
| `Ident`（`SymParam` / `SymLocal`） | `LocalGet{その番号, 型}` |
| `Ident`（`SymFunc`） | `FuncValue{その関数の ID}`。テーブルに追加する |
| `-X` / `!X` | `Unary{Neg / Not}` |
| `X op Y`（`+ - * / == != < <= > >=`） | `Binary` |
| `X && Y` | `If{X, Y, BoolConst(false), Bool}` |
| `X \|\| Y` | `If{X, BoolConst(true), Y, Bool}` |
| `F(A...)`、`F` が `SymFunc` の `Ident` | `Call{その関数の ID, A..., 結果の型}` |
| `F(A...)`、それ以外 | `CallIndirect{F の変換結果, F の型の Sig, A...}` |
| `if C {T} else E` | `If{C, T, E, 型}` |
| `{ lets; R }`、`lets` が空 | `R` の変換結果（`Block` を作らない） |
| `{ lets; R }` | `Block{Let..., R}` |
| `FuncLit` | 関数を持ち上げ、`FuncValue{その ID}`。テーブルに追加する |

「テーブルに追加する」は、`Module.Table` にその ID がまだなければ末尾に追加することを指す。

式の型は `info.Types` から取る。`Ident` のシンボルは `info.Uses`、`let` のシンボルは `info.Defs`、引数のシンボルは `info.Params` から取る。
匿名関数の本体の中でトップレベル関数を呼ぶ場合も、`Call` を使う。

## テスト観点

テーブル駆動。ソースを `parser.ParseFile` → `typecheck.Check` → `Lower` と通し、`ir.Format` の結果を期待文字列と完全一致で比較する。各テストとサブテストで `t.Parallel()`。

### `ir`

* 手組みの `Module` で、各ノードの表示形式と `Format` の行構成（空のテーブル `(table)` を含む）を確認する。
* `Type()` の表を確認する。

### `lower`

* `fn main() -> Int { 42 }` → `(func 0 main (sig () Int) (locals) 42)`、`(table)`、`(main 0)`
* `fib` + `main`: 再帰呼び出しが `(call 0 ...)`、`main` からの呼び出し
* `main` が先頭でない場合の `(main N)`
* ローカル変数: `calc` の例で `(block (let 1 ...) (let 2 ...) (local 2))`
* シャドーイング: `{ let x = 1 let x = x + 1 x }` → `(block (let 0 1) (let 1 (add (local 0) 1)) (local 1))`
* `let` のないネストしたブロックが展開される
* `&&` / `||` の展開、単項演算子
* `Bool` 同士の `==`
* 関数値: `apply(double, 3)` で `double` がトップレベル関数のとき、`(func.ref ID)` がテーブルに入る
* 同じ関数を 2 回値として使ってもテーブルは 1 件
* 匿名関数: `lambda$0` が末尾に追加され、`(func.ref ID)` と `call.indirect` の `Sig`
* 匿名関数の中の匿名関数: `lambda$0`、`lambda$1` の順序
* 引数の関数型の値を呼ぶ `f(x)` → `(call.indirect (sig (Int) Int) (local 0) (local 1))`
* 関数を返す関数の呼び出し `pick(true)(3)` → `call.indirect` の callee が `(call ...)`
* 相互再帰
