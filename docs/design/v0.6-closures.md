# 設計: v0.6 クロージャ

## 目的

ADR-0008 のとおり、匿名関数から外側の変数を捕捉できるようにし、関数値を「テーブルのインデックスと環境ポインタの組（`i64`）」で表す。

対象外にすること:

* 局所的な再帰関数（`let rec`）
* 関数値の比較
* 環境やクロージャの回収（GC）
* 捕捉のない関数値の静的配置などの最適化（もともと確保しない）
* 複数エラーの報告

## 関連する ADR

* ADR-0002: 関数値（funcref テーブル）、値の表現
* ADR-0003: ヒープのブロックのレイアウト、バンプアロケータ
* ADR-0004: 特殊化
* ADR-0005: 末尾呼び出し
* ADR-0006: 一般化した `let` を参照ごとに IR にする方式
* ADR-0008: 本書の決定

## 前提

`docs/design/v0.5-type-inference.md` までが実装済みであること。本書は差分だけを書く。
1 つの実装単位で、型検査・IR・IR 生成・WebAssembly・サンプル・E2E をまとめて実装する（途中の状態ではテストが通らないため）。

## `internal/ir`

```go
// Module.Table のコメントを次にする:
// Table lists every function used as a value, without duplicates, in order
// of first use. A FuncRef value holds an index into Table. Every function in
// Table takes an environment pointer (Ptr) as its last parameter, after the
// parameters of the source-level function type.

// FuncValue produces a FuncRef value for Func, which must appear in
// Module.Table. Env yields the address of the environment block passed as
// the last argument whenever the value is called; it is nil for a function
// that captures nothing, which passes address 0.
type FuncValue struct {
	Func FuncID
	Env  Expr // nil, or a Ptr expression (a Construct with Tag 0)
}

// CallIndirect のコメントに次を足す:
// Sig is the signature of the source-level function type and does not
// include the environment parameter; the callee's environment is passed
// after Args.
```

`print.go` の表示:

* `Env == nil`: これまでどおり `(func.ref N)`
* `Env != nil`: `(func.ref N ENV)`（`ENV` は `FormatExpr(Env)`）

## `internal/lower`

### 捕捉の解析（`captures.go`、新規）

```go
// captureSet computes, for anonymous functions, the local symbols they read
// from enclosing functions.
type captureSet struct {
	info     *typecheck.Info
	polyLets map[*typecheck.Symbol]*ast.LetStmt
	memo     map[*ast.FuncLit][]*typecheck.Symbol
}

// of returns the parameters, lets and pattern variables that lit reads but
// does not declare, in order of first occurrence in a depth-first,
// left-to-right walk of its body. A use of a generalized let contributes
// the captures of the let's value instead of the let itself, since a
// generalized let has no run-time local. A nested anonymous function
// contributes its own captures that lit does not declare.
func (cs *captureSet) of(lit *ast.FuncLit) []*typecheck.Symbol
```

```text
of(lit):
    if memo[lit] exists: return it
    declared = {info.Params[p] for p in lit.Params}
    out = ordered set
    visit(e):
        Ident:
            sym = info.Uses[e]
            if sym.Kind is SymParam or SymLocal:
                if len(sym.TypeParams) > 0:          // 一般化した let
                    for s in valueCaptures(polyLets[sym].Value): if !declared[s]: add s
                else if !declared[sym]: add sym
        FuncLit (入れ子): for s in of(e): if !declared[s]: add s
        BlockExpr: for each let: visit(Value); declared += info.Defs[let]; then visit(Result)
        MatchExpr: visit(Scrutinee); for each arm: declared += パターンの VarPat の info.PatVars; visit(Body)
        その他: 子を左から順に visit
    visit(lit.Body)
    memo[lit] = out; return out

valueCaptures(v):                  // 一般化した let の右辺（FuncLit か Ident）
    FuncLit: return of(v)
    Ident:  上の Ident と同じ規則を、declared を空として適用した結果
```

シンボルは宣言ごとに異なるので、`declared` は匿名関数ごとに 1 つの集合でよい（宣言より前に参照されることはない）。

### 関数値（`lowerIdent` の `SymFunc`）

```text
id = funcID(e, sym)
w = refWrapper(id)
addTable(w)
return &ir.FuncValue{Func: w}

refWrapper(id):
    if refs[id] exists: return it
    target = module.Funcs[id]
    sig = target.Sig に Ptr を最後の引数として足したもの
    wrapper = &ir.Func{Name: target.Name + "$ref", Sig: sig, Locals: sig.Params のコピー}
    wrapper.Body = &ir.Call{Func: id, Args: [LocalGet{i, target.Sig.Params[i]} for i in 0..len(target.Sig.Params)-1], T: target.Sig.Result, Tail: true}
    append wrapper to module.Funcs; refs[id] = その FuncID
```

ラッパーは、最初に値として使われた時点で `module.Funcs` の末尾に追加する。

### 匿名関数（`lowerFuncLit`）

`lowerFuncLit(fn, locals, e)` に引数を足す（呼び出し側の `convert` も直す）。

```text
lowerFuncLit(fn, locals, e):
    sig = info.FuncLits[e]
    caps = captures.of(e)
    irSig = sigOf(sig) に Ptr を最後の引数として足したもの
    lam = &ir.Func{Name: "lambda$N", Sig: irSig}; lambdas++; append to module.Funcs
    lowerClosureBody(lam, e.Params, caps, e.Body)
    addTable(lam の id)
    if len(caps) == 0: return &ir.FuncValue{Func: id}
    fields = [LocalGet{locals[s], valType(s.Type)} for s in caps]   // locals に無ければ panic
    return &ir.FuncValue{Func: id, Env: &ir.Construct{Tag: 0, Fields: fields}}

lowerClosureBody(lam, params, caps, body):
    locals = {}; lam.Locals = params の値型
    env = LocalID(len(params)); lam.Locals に Ptr を追加
    lets = []
    for i, s in caps:
        id = LocalID(len(lam.Locals)); lam.Locals に valType(s.Type) を追加; locals[s] = id
        lets に &ir.Let{Local: id, Value: &ir.Field{Local: env, Index: i, T: valType(s.Type)}} を追加
    body = lowerExpr(lam, locals, body)
    if len(lets) > 0: body = &ir.Block{Lets: lets, Result: body}
    lam.Body = body; 結果の型の検査と markTailCalls は lowerFunc と同じ
```

`lowerFunc` と共通の部分（引数の局所変数、結果の型の検査、`markTailCalls`）は関数に切り出してよい。
匿名関数の本体は、外側の関数を変換している途中で変換する（今と同じ）。`l.env` は外側の特殊化のものを使う。

### 一般化した `let`（`lowerPolyUse`）

変更しない。右辺が匿名関数なら `lowerFuncLit` が参照の場所の `locals` から環境を作る。
参照の場所が別の匿名関数の中なら、その匿名関数は `captures.of` によって右辺の捕捉を捕捉しているので、`locals` に入っている。

### 関数値の呼び出し（`lowerCall`）

変更しない（`CallIndirect.Sig` は利用者の型のまま）。

## `internal/wasm`

* `wasmValType(ir.FuncRef)` を `valI64` にする。`wasmAsIR` は `FuncRef` を `ir.Int` に写す（`i64` だから）。
  データ型のフィールドの読み書き（`Field`、`new` ヘルパー）は、値型から `i64.load` / `i64.store` を選ぶので、`FuncRef` のフィールドは `i64` で読み書きされる。値型ではなく `ir.Int` かどうかで分岐している箇所があれば、`wasmValType` で分岐するように直す。
* `collectTypes`: `CallIndirect` の型は、`c.Sig.Params` の後ろに `ir.Ptr` を足したシグネチャで登録する（テーブルの関数のシグネチャと同じ添字を共有する）。
* `FuncValue` の符号化:

```text
Env == nil:  i64.const tableIndex(Func)
Env != nil:  expr(Env); i64.extend_i32_u; i64.const 32; i64.shl; i64.const tableIndex(Func); i64.or
```

* `CallIndirect` の符号化（`scratch` はその関数の作業用の局所変数）:

```text
for each arg: expr(arg)
expr(Callee); local.tee scratch
i64.const 32; i64.shr_u; i32.wrap_i64          // 環境のアドレス（最後の引数）
local.get scratch; i32.wrap_i64                 // テーブルのインデックス
call_indirect typeIndex(Sig + Ptr) 0            // Tail なら return_call_indirect
```

* 作業用の局所変数: 本体に `CallIndirect` を含む関数では、`fn.Locals` の後ろに `i64` の局所変数を 1 つ足して符号化する（番号は `len(fn.Locals)`）。
  引数を積む途中の入れ子の呼び出しが `scratch` を書き換えても、`local.tee` から `local.get` までの間には他の命令が入らないので安全である。
  `encodeLocals` と `encodeBody` を、この局所変数を含めるように変える（IR の `Func.Locals` は変えない）。
  - 新しい opcode: `i64.shl`（`0x86`）、`i64.shr_u`（`0x88`）、`i64.or`（`0x84`）、`i64.extend_i32_u`（`0xad`）、`i32.wrap_i64`（`0xa7`）、`local.tee`（`0x22`）。

## エラーケースと扱い

* 型検査のエラーは減るだけで、増えない。
* IR 生成で、捕捉した Symbol が `locals` に無い場合、`Field` の `Local` が `Ptr` でない場合は、型検査や IR 生成のバグとして `panic` する（既存の方針）。
