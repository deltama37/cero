# 設計: v0.3 IR 生成（型引数の表現ごとの特殊化）・サンプル・E2E

## 目的

型検査済みの多相な関数を、ADR-0004 の「型引数の表現ごとの特殊化」で IR に変換する。
これにより、型パラメータを使うプログラムを `ceroc build` / `ceroc run` で実行できるようにする。

対象外にすること:

* IR のノードと値型の追加・変更（v0.2 のまま使う）
* WebAssembly バックエンドの変更（ADR-0004 で変更しないと決めた）
* 使われない多相な関数の出力（出力しない）、使われない多相でない関数の削除（v0.2 と同じく出力する）
* データ型の特殊化（ADR-0004 で特殊化しないと決めた）
* 型引数の値型をさらに WebAssembly の型まで縮める共有（ADR-0004 で採用しなかった）

## 関連する ADR

* ADR-0002: 値の表現、lambda lifting、`ceroc run`
* ADR-0003: データ型の値の表現、ブロックのレイアウト
* ADR-0004: 型引数の表現ごとの特殊化、データ型を特殊化しないこと

## 前提

`docs/design/v0.2-backend.md`、`docs/design/v0.3-frontend.md`、`docs/design/v0.3-typecheck.md` の内容が実装済みであること。本書は差分だけを書く。

末尾呼び出し（ADR-0005、`docs/design/tail-calls.md`）は実装済みである。
`lowerFunc` の最後で `markTailCalls(fn.Body)` を呼び、末尾位置の `ir.Call` と `ir.CallIndirect` に `Tail` を付ける処理は変えずに保つ。
本書の変更は、呼び出し先の `FuncID` の決め方、関数の並び、値型の求め方だけに関わり、末尾呼び出しの判定とは独立している。
特殊化の本体も持ち上げた匿名関数の本体も `lowerFunc` で変換するので、どちらにも末尾呼び出しの印が付く。
本書の IR の期待値は、末尾位置の呼び出しを `(return.call ...)` / `(return.call.indirect ...)` と表示した形で書く。

## `internal/lower`

### 状態

```go
type lowerer struct {
	info      *typecheck.Info
	module    *ir.Module
	declID    map[*ast.FuncDecl]ir.FuncID            // functions without type parameters
	instances map[*ast.FuncDecl]map[string]ir.FuncID // specializations of generic functions, keyed by repKey
	queue     []*instance                            // specializations whose bodies are not lowered yet, in creation order
	env       map[*types.TypeParam]ir.ValType        // representation of each type parameter of the function being lowered; nil when it has none
	lambdas   int
}

// instance is one specialization of a generic function.
type instance struct {
	decl *ast.FuncDecl
	id   ir.FuncID
	env  map[*types.TypeParam]ir.ValType
}
```

### 処理の流れ（`Lower`）

公開 API（`Lower(file, info) *ir.Module`）のシグネチャは変えない。

```text
Lower(file, info):
    l = lowerer{..., instances: empty map}

    // 1. functions without type parameters, in source order
    for d in file.Funcs:
        sym = info.Funcs[d]; nil → panic (v0.2)
        if len(sym.TypeParams) > 0: continue
        id = FuncID(len(module.Funcs))
        module.Funcs.append(&ir.Func{Name: d.Name, Sig: l.sigOf(sym.Type)})
        declID[d] = id
        if d.Name == "main": module.Main = id; foundMain = true
    if !foundMain: panic (v0.2)

    // 2. their bodies, in source order
    for d in file.Funcs:
        if d is not in declID: continue
        l.env = nil
        lowerFunc(module.Funcs[declID[d]], d.Params, d.Body)

    // 3. specializations, in creation order (FIFO)
    while len(l.queue) > 0:
        inst = l.queue[0]; l.queue = l.queue[1:]
        l.env = inst.env
        lowerFunc(module.Funcs[inst.id], inst.decl.Params, inst.decl.Body)

    l.env = nil
    return module
```

* 型パラメータを持たない関数の `FuncID` は、それらだけを数えたソース順の番号になる。
  型パラメータを使わないプログラムでは、v0.2 の番号（`file.Funcs` の添字）と一致し、IR の出力は v0.2 と 1 文字も変わらない。
* 特殊化と持ち上げた匿名関数の `FuncID` は、作った順に `len(module.Funcs)` から振る（匿名関数は v0.2 と同じく、変換中に見つけた時点で作る）。
* 匿名関数は、それを見つけた関数の変換の中で直ちに変換する（v0.2 のまま）。そのとき `l.env` は外側の関数のものなので、匿名関数の型注釈の型パラメータも外側の特殊化の値型に写る。

### 特殊化

```go
// funcID returns the IR function for a use at id of the SymFunc sym,
// creating a specialization when sym has type parameters.
func (l *lowerer) funcID(id *ast.Ident, sym *typecheck.Symbol) ir.FuncID

// instance returns the specialization of the generic function sym for reps,
// creating it and queueing its body when it does not exist yet.
func (l *lowerer) instance(sym *typecheck.Symbol, reps []ir.ValType) ir.FuncID

// repKey joins the names of reps with ",", e.g. "Int,Ptr".
func repKey(reps []ir.ValType) string
```

```text
funcID(id, sym):
    if len(sym.TypeParams) == 0:
        return declID[sym.Decl]   // missing → panic "lower: no function id for 'NAME' at POS" (v0.2)
    args = info.TypeArgs[id]
    if len(args) != len(sym.TypeParams): panic "lower: missing type arguments for 'NAME' at POS"
    reps = [l.valType(a) for a in args]    // under the current l.env
    return instance(sym, reps)

instance(sym, reps):
    key = repKey(reps)
    if id, ok = instances[sym.Decl][key]: return id
    env = {sym.TypeParams[i]: reps[i] for each i}
    id = FuncID(len(module.Funcs))
    module.Funcs.append(&ir.Func{Name: sym.Decl.Name + "[" + key + "]", Sig: sigIn(env, sym.Type)})
    instances[sym.Decl][key] = id      // allocate the inner map on first use
    queue.append(&instance{decl: sym.Decl, id: id, env: env})
    return id
```

* 特殊化の IR の関数名は `identity[Int]`、`map[Int,Bool]`、`depth[Ptr]` の形とする（値型の名前は `ir.ValType.String()`）。
* 型引数が外側の関数の型パラメータを含む場合（`length[T]` の中の `length(r)` の型引数 `T` など）は、現在の `l.env` で値型に写す。
  `List[T]` のような型の適用は、`T` にかかわらず `Ptr` になる。

### 関数の参照と呼び出し

* `lowerIdent` の `SymFunc`: `id = funcID(e, sym)`; `addTable(id)`; `FuncValue{id}`。
* `lowerCall` の `SymFunc`: `fid = funcID(id, sym)` を、**引数を変換する前に**求め、`Call{Func: fid, Args: 引数, T: 結果の値型}` とする（v0.2 と同じ順序）。
* 構築子（`SymCtor`）の変換は v0.2 のまま。`Construct` のフィールドの値型は、変換した引数の式の型から決まるので、`Info.TypeArgs` は使わない。

### 値型

```go
func (l *lowerer) valType(t types.Type) ir.ValType { return valTypeIn(l.env, t) }
func (l *lowerer) sigOf(t types.Type) ir.Sig       { return sigIn(l.env, t) }

// valTypeIn maps a type to its IR value type. Type parameters are looked up
// in env.
func valTypeIn(env map[*types.TypeParam]ir.ValType, t types.Type) ir.ValType

// sigIn maps a function type to an IR signature, looking up type parameters
// in env. It panics when t is not a *types.Func.
func sigIn(env map[*types.TypeParam]ir.ValType, t types.Type) ir.Sig
```

| 型 | 値型 |
| --- | --- |
| `types.IntType` | `ir.Int` |
| `types.BoolType` | `ir.Bool` |
| `*types.Func` | `ir.FuncRef` |
| `*types.Named` | `ir.Ptr` |
| `*types.TypeParam` | `env[t]`。なければ `panic("lower: unbound type parameter 'NAME'")` |
| それ以外（`*types.Meta` を含む） | `panic("lower: unhandled type %T")` |

`sigIn` の本体は v0.2 の `sigOf` と同じで、引数と結果の値型を `valTypeIn(env, ...)` で求める。

### パターン変数の値型

`armBody` の構築子パターンの `VarPat` で、フィールドのローカルの値型を `ctor.Fields[i]` ではなく、パターン変数のシンボルの型から求める。

```text
sym = l.patVar(arg)
fieldType = l.valType(sym.Type)      // v0.2: l.valType(ctor.Fields[i])
```

`ctor.Fields[i]` はデータ型の型パラメータ（`Cons` の `T`）を含みうるが、パターン変数のシンボルの型は型検査で型引数に置き換えられている（`docs/design/v0.3-typecheck.md` の `checkPattern`）。
引数の個数の検査（`len(pat.Args) != len(ctor.Fields)` の `panic`）は残す。

### 変えないもの

`lowerExpr` の「IR の型と型検査の型の一致」の検査、`lowerMatch`（照合対象の型の分岐は `docs/design/v0.3-typecheck.md` で `*types.Named` に変更済み）、`lowerFuncLit`、`addTable`、`binOp` などは変えない。
`valType` と `sigOf` を呼んでいる箇所は、そのまま `l.env` を使うようになる。

## サンプル

### `examples/generic_list.cero`（新規）

```text
// expected output: 26

type List[T] =
    | Nil
    | Cons(T, List[T])

fn range(from: Int, to: Int) -> List[Int] {
    if from > to {
        Nil
    } else {
        Cons(from, range(from + 1, to))
    }
}

fn map[T, U](xs: List[T], f: T -> U) -> List[U] {
    match xs {
        Nil => Nil,
        Cons(x, rest) => Cons(f(x), map(rest, f)),
    }
}

fn foldl[T, A](xs: List[T], acc: A, f: (A, T) -> A) -> A {
    match xs {
        Nil => acc,
        Cons(x, rest) => foldl(rest, f(acc, x), f),
    }
}

fn length[T](xs: List[T]) -> Int {
    foldl(xs, 0, fn(n: Int, x: T) -> Int { n + 1 })
}

fn sum(xs: List[Int]) -> Int {
    foldl(xs, 0, fn(acc: Int, x: Int) -> Int { acc + x })
}

fn count(bs: List[Bool]) -> Int {
    foldl(bs, 0, fn(n: Int, b: Bool) -> Int { if b { n + 1 } else { n } })
}

fn main() -> Int {
    let xs = range(1, 4)
    let doubled = map(xs, fn(x: Int) -> Int { x * 2 })
    let flags = map(xs, fn(x: Int) -> Bool { x > 2 })
    sum(doubled) + length(flags) + count(flags)
}
```

`sum(doubled)` = 2 + 4 + 6 + 8 = 20、`length(flags)` = 4、`count(flags)` = 2 で、合計 26。

### `examples/option.cero`（新規）

```text
// expected output: 42

type Option[T] =
    | None
    | Some(T)

fn withDefault[T](o: Option[T], d: T) -> T {
    match o {
        None => d,
        Some(x) => x,
    }
}

fn mapOption[T, U](o: Option[T], f: T -> U) -> Option[U] {
    match o {
        None => None,
        Some(x) => Some(f(x)),
    }
}

fn safeDiv(a: Int, b: Int) -> Option[Int] {
    if b == 0 {
        None
    } else {
        Some(a / b)
    }
}

fn main() -> Int {
    let a = withDefault(mapOption(safeDiv(84, 2), fn(x: Int) -> Int { x - 2 }), 0)
    let b = withDefault(safeDiv(1, 0), 2)
    let nested = Some(Some(true))
    let c = if withDefault(withDefault(nested, None), false) { 0 } else { 100 }
    a + b + c
}
```

`a` = 42 − 2 = 40、`b` = 2、`c` = 0 で、合計 42。`withDefault` は `[Int]`、`[Ptr]`、`[Bool]` の 3 つに特殊化される。

```text

    | None
    | Some(T)

fn countdown[T](n: Int, x: T) -> T {
    if n == 0 { x } else { countdown(n - 1, x) }
}

    if n == 0 { acc } else { loop(n - 1, step(acc), step) }
}

    let b = match countdown(10000000, Some(true)) {

        Some(t) => if t { 2 } else { 0 },

}
```
