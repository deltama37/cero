# 設計: v0.3 型検査（型パラメータ・インスタンス化・単一化）

## 目的

`docs/design/v0.3-frontend.md` で追加した型パラメータの宣言と型の適用について、名前解決と型検査を行う。
多相な関数と構築子の参照をインスタンス化し、型引数を単一化で決め、その結果を IR 生成（`docs/design/v0.3-backend.md`）が使えるように `Info` に記録する。

対象外にすること:

* let 多相、関数の引数と戻り値の型の推論、明示的な型引数（ADR-0004 で v0.3 の対象外）
* 型パラメータの値の比較と照合（ADR-0004 でエラーにすると決めた。既存のメッセージで報告する）
* 決まらない型引数の defaulting（ADR-0004 でエラーにすると決めた）
* IR 生成での特殊化（`docs/design/v0.3-backend.md`）
* 複数エラーの報告と警告

## 関連する ADR

* ADR-0002: 比較できる型、クロージャ禁止、エラー報告
* ADR-0003: 型宣言、構築子、`match`、パターン、網羅性
* ADR-0004: 型パラメータの規則、硬い型変数と単一化変数、単一化、決まらない型引数のエラー

## 前提

`docs/design/v0.2-typecheck.md` と `docs/design/v0.3-frontend.md` の内容が実装済みであること。本書は差分だけを書く。

## `internal/types`

パッケージのコメントを `// Package types defines the types of Cero.` に、`Type` のコメントを `// Type is a Cero type.` に変える。

### 型の一覧

```go
// Data is a declared algebraic data type. It is not a Type: a use of the
// type is a *Named that points to it. Each type declaration has exactly one
// *Data.
type Data struct {
	Name   string
	Params []*TypeParam // declaration order; nil when the type has no parameters
	Ctors  []*Ctor      // declaration order
}

// Ctor is one constructor of a Data type. Fields may refer to Data.Params.
type Ctor struct {
	Name   string
	Index  int // position in Data.Ctors; used as the runtime tag
	Fields []Type
	Data   *Data
}

// Named is a declared data type applied to type arguments.
// len(Args) == len(Data.Params), and Args is nil when Data has no parameters.
type Named struct {
	Data *Data
	Args []Type
}

// TypeParam is a rigid type variable declared in "[T, U]" of a function or
// type declaration. Each declaration gets its own *TypeParam, and a type
// parameter is equal only to itself.
type TypeParam struct {
	Name string
}

// Meta is a unification variable. The type checker creates one per type
// parameter each time it instantiates a generic name. Solution is nil until
// unification assigns a type to it.
type Meta struct {
	Name     string // name of the type parameter it stands for; used by String
	Solution Type
}
```

* `*Named`、`*TypeParam`、`*Meta` はポインタレシーバで `Type` を実装する。`*Data` は `Type` を実装しない（`String()` と `isType()` を削除する）。
* `IntType`、`BoolType`、`*Func` は変えない。
* ファイル末尾の実装の確認（`var _ Type = ...`）から `(*Data)(nil)` を外し、`(*Named)(nil)`、`(*TypeParam)(nil)`、`(*Meta)(nil)` を加える。

### `String()`

| 型 | 表示 | 例 |
| --- | --- | --- |
| `*Named`（`Args` が空） | `Data.Name` | `IntList` |
| `*Named`（`Args` あり） | `Name[A1, A2, ...]`（`", "` で区切る） | `Option[Int]`、`Pair[Int, Bool]`、`Option[Int -> Int]`、`List[List[T]]` |
| `*TypeParam` | `Name` | `T` |
| `*Meta`（解あり） | `Solution.String()` | `Int` |
| `*Meta`（解なし） | `"?" + Name` | `?T` |

`*Func` の `String()` の「引数が 1 つで、それが関数型なら括弧で囲む」判定は、`t.Params[0]` の代わりに `Prune(t.Params[0])` で行う。
解が関数型の単一化変数を引数に持つ関数型も `(Int -> Int) -> Int` と表示するためである。

### 公開する関数

```go
// Prune follows solved metas starting at t and returns the first type that
// is not a solved *Meta. It returns t itself when t is not a solved *Meta.
func Prune(t Type) Type

// Resolve returns t with every solved *Meta replaced by its resolved
// solution. Unsolved metas are kept. It builds new *Func and *Named values
// where needed and never modifies t.
func Resolve(t Type) Type

// Subst returns t with each params[i] replaced by args[i]. Solved metas are
// followed. It panics when len(params) != len(args). When params is empty it
// returns t unchanged.
func Subst(t Type, params []*TypeParam, args []Type) Type

// Mentions reports whether v, a *TypeParam or *Meta, occurs in t, comparing
// by pointer and following solved metas.
func Mentions(t Type, v Type) bool

// SelfType returns d applied to its own parameters, e.g. Option[T] for
// "type Option[T]". Args is nil when d has no parameters.
func SelfType(d *Data) *Named
```

処理の流れ:

```text
Prune(t):
    while t is *Meta and t.Solution != nil: t = t.Solution
    return t

Resolve(t):
    t = Prune(t)
    switch t:
    case *Func:  return &Func{Params: Resolve each, Result: Resolve(t.Result)}
    case *Named: if len(t.Args) == 0: return t
                 return &Named{Data: t.Data, Args: Resolve each}
    default:     return t   // IntType, BoolType, *TypeParam, unsolved *Meta

Subst(t, params, args):
    if len(params) != len(args): panic
    if len(params) == 0: return t
    t = Prune(t)
    switch t:
    case *TypeParam: if t == params[i] for some i: return args[i]; else return t
    case *Func:  return &Func{Params: Subst each, Result: Subst(t.Result, ...)}
    case *Named: if len(t.Args) == 0: return t
                 return &Named{Data: t.Data, Args: Subst each}
    default:     return t

Mentions(t, v):
    t = Prune(t)
    if t == v (pointer comparison of the interface values): return true
    switch t:
    case *Func:  return any Mentions(p, v) for p in Params, or Mentions(Result, v)
    case *Named: return any Mentions(a, v) for a in Args
    default:     return false
```

### `Equal`

```text
Equal(a, b):
    a, b = Prune(a), Prune(b)
    switch a:
    case IntType, BoolType: same as v0.2
    case *Func: same as v0.2 (Equal on params and result)
    case *Named: b is *Named, a.Data == b.Data, len(a.Args) == len(b.Args), Equal on each pair of args
    case *TypeParam: b is the same pointer
    case *Meta: b is the same pointer   // only unsolved metas reach here
    default: false
```

データ型は名前的なので、`*Named` の比較は `Data` のポインタと型引数だけを見る。構築子のフィールドはたどらないので、再帰型でも停止する。

## `internal/typecheck`

### 公開要素の変更

```go
type Symbol struct {
	Kind SymbolKind
	Name string
	Type types.Type
	Pos  diag.Pos
	Decl *ast.FuncDecl
	Ctor *types.Ctor
	// TypeParams are the type parameters Type is generic over: the function's
	// own for a generic SymFunc, Ctor.Data.Params for a SymCtor, and nil
	// otherwise.
	TypeParams []*types.TypeParam
}

type Info struct {
	// ... v0.2 fields unchanged ...

	// TypeArgs holds, for every Ident whose symbol has TypeParams, the type
	// arguments of that use in TypeParams order.
	TypeArgs map[*ast.Ident][]types.Type
}
```

* `Check` は `TypeArgs` も必ず割り当てる（空の map）。
* `SymFunc` の `Type` は宣言どおりの `*types.Func` で、`TypeParams` を含みうる。
* `SymCtor` の `Type` は、フィールドがなければ `types.SelfType(data)`、あれば `&types.Func{Params: ctor.Fields, Result: types.SelfType(data)}` とする（v0.2 の `ctor.Data` を `SelfType` に置き換える）。
* **`Check` が返す `Info` には `*types.Meta` が 1 つも現れない。**
  `Types` の値、`Defs`・`PatVars`・`Params` のシンボルの `Type`、`FuncLits` の値、`TypeArgs` の値のすべてが対象である。
  多相な関数の本体の中の型は、その関数の `*types.TypeParam` を含みうる。

### checker の状態

```go
type checker struct {
	info    *Info
	globals map[string]*Symbol
	datas   map[string]*types.Data
	ctors   map[string]*types.Ctor
	tparams map[string]*types.TypeParam // type parameters in scope; nil outside generic declarations
	metas   []*pendingMeta              // created while checking the current top-level function, in creation order
}

// pendingMeta remembers where a unification variable was created so that an
// unsolved one can be reported.
type pendingMeta struct {
	meta  *types.Meta
	owner string   // name of the instantiated function or constructor
	pos   diag.Pos // position of the instantiating Ident
}
```

### 処理の流れ（`Check`）

```text
Check(file):
    c = checker{..., info.TypeArgs = empty map}

    // 0a. type names (v0.2 のまま). data = &types.Data{Name: d.Name}

    // 0b. type parameters of types, in source order
    for d in file.Types:
        datas[d.Name].Params = declareTypeParams(d.TypeParams)

    // 0c. constructors (v0.2 の 0b)
    for d in file.Types:
        data = datas[d.Name]
        c.tparams = scopeOf(data.Params)
        for i, cd in d.Ctors:
            duplicate check (v0.2)
            fields = resolveType(f) for f in cd.Fields
            ctor = &types.Ctor{cd.Name, i, fields, data}
            ...(v0.2)
            globals[cd.Name] = &Symbol{Kind: SymCtor, ..., Type: ctorType(ctor), Ctor: ctor, TypeParams: data.Params}
        c.tparams = nil

    // 1. function signatures
    for d in file.Funcs:
        constructor conflict / duplicate function (v0.2)
        tps = declareTypeParams(d.TypeParams)
        c.tparams = scopeOf(tps)
        sig = resolveFuncType(d.Params, d.Result)
        for i, tp in tps:
            if !types.Mentions(sig, tp):
                error at d.TypeParams[i].Pos "type parameter 'NAME' is not used in the signature of 'FUNC'"
        c.tparams = nil
        globals[d.Name] = info.Funcs[d] = &Symbol{Kind: SymFunc, ..., Type: sig, Decl: d, TypeParams: tps}

    // 2. bodies
    for i, d in file.Funcs:
        c.tparams = scopeOf(info.Funcs[d].TypeParams)
        c.metas = nil
        checkFunc(&funcCtx{}, d.Params, sigs[i], d.Body)
        checkSolved()
        c.tparams = nil

    // 3. main
    main = globals["main"]; missing → v0.2 のエラー
    if len(main.TypeParams) > 0: error at main.Pos "function 'main' cannot have type parameters"
    type check () -> Int (v0.2)

    // 4. remove metas from Info
    resolveInfo()
    return info
```

* 手順 0b は全型の名前の登録（0a）の後に行うので、型パラメータとデータ型の名前の衝突を、後方で宣言された型についても検出できる。
* 手順 0c は全型の型パラメータの登録（0b）の後に行うので、フィールドに書いた型の適用の個数を、後方で宣言された型についても検査できる。
* 手順 3 の `main` の型パラメータの検査は、手順 1 の「型パラメータが使われていない」検査より後である。
  そのため `fn main[T]() -> Int { 0 }` は手順 1 の `type parameter 'T' is not used in the signature of 'main'` になる。

```go
// scopeOf returns a name-to-parameter map, or nil when ps is empty.
func scopeOf(ps []*types.TypeParam) map[string]*types.TypeParam

func (c *checker) declareTypeParams(ps []*ast.TypeParam) ([]*types.TypeParam, *diag.Error)
```

```text
declareTypeParams(ps):
    if len(ps) == 0: return nil
    seen = set; out = []
    for p in ps:
        if p.Name is "Int" or "Bool" or p.Name in datas:
            error at p.Pos "type parameter 'NAME' conflicts with type 'NAME'"
        if p.Name in seen: error at p.Pos "duplicate type parameter 'NAME'"
        seen.add(p.Name); out.append(&types.TypeParam{Name: p.Name})
    return out
```

### 型の解決（`resolveType`）

`*ast.NamedType` の処理を次のように変える。`*ast.FuncType` の処理は変えない（引数と結果を `resolveType` で解決するので、そこにも以下が適用される）。

```text
case *ast.NamedType:
    M = len(t.Args)
    if tp = c.tparams[t.Name]; tp != nil:
        if M != 0: error at t.Pos "wrong number of type arguments for 'NAME': expected 0, found M"
        return tp
    if t.Name is "Int" or "Bool":
        if M != 0: error at t.Pos "wrong number of type arguments for 'NAME': expected 0, found M"
        return types.Int or types.Bool
    if data = datas[t.Name]:
        N = len(data.Params)
        if M != N: error at t.Pos "wrong number of type arguments for 'NAME': expected N, found M"
        if N == 0: return &types.Named{Data: data}
        args = resolveType(a) for a in t.Args, left to right
        return &types.Named{Data: data, Args: args}
    error at t.Pos "unknown type 'NAME'"   (v0.2)
```

* 個数の検査を、型引数の解決より先に行う。
* 関数の本体の中の `let` の型注釈と匿名関数の型注釈も `resolveType` で解決するので、手順 2 で設定した `c.tparams` により、外側の関数の型パラメータを参照できる。

### インスタンス化

```go
// instantiate returns sym.Type with sym.TypeParams replaced by fresh metas
// and records the metas in Info.TypeArgs[id]. For a symbol without type
// parameters it returns sym.Type and records nothing.
func (c *checker) instantiate(sym *Symbol, id *ast.Ident) types.Type
```

```text
instantiate(sym, id):
    if len(sym.TypeParams) == 0: return sym.Type
    args = []
    for tp in sym.TypeParams:
        m = &types.Meta{Name: tp.Name}
        c.metas.append(&pendingMeta{meta: m, owner: sym.Name, pos: id.Pos})
        args.append(m)
    info.TypeArgs[id] = args
    return types.Subst(sym.Type, sym.TypeParams, args)
```

### 名前の参照（`inferIdent`）

v0.2 の処理のうち、最後の

```text
record Uses; if SymCtor: return sym.Ctor.Data; return sym.Type
```

を次に置き換える。解決順、捕捉のエラー、フィールドを持つ構築子のエラーは変えない。

```text
record Uses[e] = sym
return instantiate(sym, e)
```

* 多相な関数を呼ばずに値として使う場合（`let f = identity`、`apply(identity, 7)`）も、ここでインスタンス化される。
* `let` や引数で束縛した名前は `TypeParams` を持たないので、参照してもインスタンス化されない（let は単相）。

### 呼び出し（`inferCall`）

* 構築子の呼び出しの分岐（`inferCtorCall`）への振り分けは v0.2 のまま。
* それ以外では `ft = infer(e.Fn)` の後、`sig, ok := types.Prune(ft).(*types.Func)` で関数型を取り出す。
  `ok` が偽なら、v0.2 と同じ `cannot call non-function value of type T`（`T` は `ft`）とする。
* 引数の個数の検査と、`expect(arg, sig.Params[i])` による引数の検査は v0.2 のまま。結果は `sig.Result`。

### 構築子の呼び出し（`inferCtorCall`）

```text
ctor = sym.Ctor
record Uses[id] = sym
if len(ctor.Fields) == 0: error at e.LParen "constructor 'NAME' has no fields; write it without parentheses"   (v0.2)
if len(e.Args) != len(ctor.Fields): error at e.LParen "wrong number of arguments: expected N, found M"          (v0.2)
ft = instantiate(sym, id).(*types.Func)
record Types[e.Fn] = ft
for i: expect(e.Args[i], ft.Params[i])
return ft.Result
```

### 型の一致: `Equal` から単一化へ

次の 4 か所で、`types.Equal` による比較を `unify` に置き換える。エラーのメッセージと位置は変えない。

| 場所 | v0.3 の処理 |
| --- | --- |
| `expect(e, want)` | `got = infer(e)`; `if !unify(want, got)`: `expected WANT, found GOT` |
| `inferIf` | `if !unify(tt, et)`: `if branches have different types: TT and ET` |
| `inferMatch` のアームの型 | 最初のアームの型を `result` とし、以降は `if !unify(result, t)`: `match arms have different types: RESULT and T` |
| `inferBlock` の型注釈付きの `let` | `expect` を使うので自動的に単一化になる |

* 引数の順序は表のとおり（期待する型が先）とする。両方が別々の未解決の単一化変数なら、1 つ目の変数に 2 つ目を割り当てる（後述の `unify`）。
* メッセージの型は、`unify` が失敗した後に `String()` で表示する。`unify` が途中まで割り当てた単一化変数は、その解で表示される。
* `==` / `!=` の検査（`types.Equal(t, types.Int)` など）、パターンの `IntPat` / `BoolPat` の検査、`main` の型の検査は、`types.Equal` のままでよい。
  `Equal` は解のある単一化変数をたどるので、`identity(1) == 1` は `Int` どうしの比較になる。
  型パラメータの値や、未解決の単一化変数の値を比較すると、v0.2 と同じ `cannot compare values of type T`（`T` や `?T`）になる。

### `match` 式（`inferMatch`）

照合対象の型の検査を次のように変える。

```text
st = infer(m.Scrutinee)
switch types.Prune(st):
case *types.Func:      error at resultPos(m.Scrutinee) "cannot match on values of type T"   (v0.2)
case *types.TypeParam: error at resultPos(m.Scrutinee) "cannot match on values of type T"
case *types.Meta:      error at resultPos(m.Scrutinee) "cannot infer the type of the matched value; add a type annotation"
st = types.Prune(st)
cov = newCoverage(st)
... (アームの処理は v0.2 のまま。ただし型の一致は前述の unify)
```

* 照合対象の型は、ここで先頭の形（`Int`、`Bool`、`*types.Named`）が決まっていなければならない。型引数（`Option[?T]` の `?T`）は未解決でもよい。
* 以降の `checkPattern` と `coverage` には、`Prune` した `st` を渡す。

`*ast.CtorPat` の処理を次のように変える。ほかのパターンの処理は v0.2 のまま。

### 網羅性の判定（`coverage`）

`catchAllCovered` と `missing` の `case *types.Data:` を `case *types.Named:` に変え、構築子の一覧を `st.Data.Ctors` から取る。ほかは v0.2 のまま。

### 未解決の単一化変数の検査

```go
func (c *checker) checkSolved() *diag.Error
```

```text
checkSolved():
    for pm in c.metas (creation order):
        if types.Prune(pm.meta) is *types.Meta:
            error at pm.pos "cannot infer type argument 'NAME' of 'OWNER'; add a type annotation"
            // NAME = pm.meta.Name, OWNER = pm.owner
```

* 解が別の未解決の単一化変数である変数も、未解決として扱う（`Prune` の結果で判定する）。
* 作成順で最初の未解決の変数を報告する。作成順は、本体を検査する順（v0.1 からの左から右、外から内の順）に一致する。

### `Info` からの単一化変数の除去

```go
func (c *checker) resolveInfo()
```

```text
resolveInfo():
    for e, t in info.Types: info.Types[e] = types.Resolve(t)
    for _, sym in info.Defs: sym.Type = types.Resolve(sym.Type)
    for _, sym in info.PatVars: sym.Type = types.Resolve(sym.Type)
    for _, args in info.TypeArgs: args[i] = types.Resolve(args[i]) for each i
```

* 手順 2 の `checkSolved` がすべての関数で成功しているので、ここではすべての単一化変数に解がある。
* 引数と匿名関数のシグネチャは型注釈から作るので、単一化変数を含まない。処理しなくてよい。

## `internal/typecheck/unify.go`

```go
// unify makes a and b equal by solving unification variables and reports
// whether it succeeded. On failure some variables may already have been
// solved; the caller reports an error and stops.
func unify(a, b types.Type) bool
```

```text
unify(a, b):
    a, b = types.Prune(a), types.Prune(b)
    if a is *Meta:
        if b is the same *Meta: return true
        if types.Mentions(b, a): return false      // occurs check
        a.Solution = b; return true
    if b is *Meta:
        if types.Mentions(a, b): return false
        b.Solution = a; return true
    switch a:
    case IntType:    return b is IntType
    case BoolType:   return b is BoolType
    case *TypeParam: return b is the same *TypeParam
    case *Func:
        b must be *Func with len(b.Params) == len(a.Params), else false
        for i: if !unify(a.Params[i], b.Params[i]): return false
        return unify(a.Result, b.Result)
    case *Named:
        b must be *Named with b.Data == a.Data and len(b.Args) == len(a.Args), else false
        for i: if !unify(a.Args[i], b.Args[i]): return false
        return true
    default: return false
```

## エラーの一覧（追加分）

| メッセージ | 位置 |
| --- | --- |
| `type parameter 'NAME' conflicts with type 'NAME'` | 型パラメータの `Pos` |
| `duplicate type parameter 'NAME'` | 2 つ目の型パラメータの `Pos` |
| `type parameter 'NAME' is not used in the signature of 'FUNC'` | 型パラメータの `Pos` |
| `wrong number of type arguments for 'NAME': expected N, found M` | `NamedType.Pos` |
| `function 'main' cannot have type parameters` | `main` の `NamePos` |
| `cannot infer type argument 'NAME' of 'OWNER'; add a type annotation` | インスタンス化した `Ident.Pos` |
| `cannot infer the type of the matched value; add a type annotation` | `resultPos(Scrutinee)` |

既存のメッセージ（`expected T, found U`、`cannot match on values of type T`、`cannot compare values of type T`、`cannot call non-function value of type T`、`unknown type 'NAME'` など）は、型の表示に `Option[Int]`、`T`、`?T` が現れうる点だけが変わる。

## `internal/lower`（最小限の追従）

`*types.Data` が `Type` でなくなるので、次の 2 か所だけを変える。ほかは変えない。

* `valType`: `case *types.Data:` → `case *types.Named:`（`ir.Ptr` を返す）
* `lowerMatch`: 照合対象の型の `case *types.Data:` → `case *types.Named:`

このフェーズでは、多相な関数を含むプログラムの IR 生成は `valType` の `unhandled type *types.TypeParam` で `panic` してよい。
型パラメータを使わないプログラムの IR は v0.2 と 1 文字も変わらない（`lower` と `wasm` の既存のテストはそのまま通る）。

## テスト観点

テーブル駆動。各テストとサブテストで `t.Parallel()`。既存のテストは、下に書いた変更を除いてそのまま通ること。

### `types`

既存のテストの `&Data{Name: "IntList"}` を `Type` として使っている箇所は、`&Named{Data: &Data{Name: "IntList"}}` に置き換える。

* `String()`:
  * `Named`: 引数なし `IntList`、`Option[Int]`、`Pair[Int, Bool]`、`Option[Int -> Int]`、`List[List[Int]]`、関数型の引数 `Option[Int] -> Int`
  * `TypeParam` `T`、`Func{Params: [T], Result: T}` → `T -> T`
  * 解のない `Meta{Name: "T"}` → `?T`、解が `Int` の `Meta` → `Int`、解が `Meta`（解 `Bool`）の `Meta` → `Bool`
  * 引数が 1 つで、それが解が `Int -> Int` の `Meta` である関数型 → `(Int -> Int) -> Int`
* `Equal`:
  * 同じ `Data` で型引数が等しい `Named` は真、型引数が違えば偽、同じ名前でも別の `Data` なら偽
  * 同じ `*TypeParam` は真、同じ名前の別の `*TypeParam` は偽、`TypeParam` と `Int` は偽
  * 解が `Int` の `Meta` と `Int` は真、解のない同じ `Meta` どうしは真、解のない別の `Meta` どうしは偽
  * 自分自身をフィールドに持つ `Data` の `Named` どうしの `Equal` が停止する
* `Prune`: 解のない `Meta` はそれ自身、`?a → ?b → Int` の連鎖は `Int`、`Int` はそれ自身
* `Resolve`: `Func{[?a], Named{List, [?b]}}`（`?a = Int`、`?b` は解なし）→ 表示が `Int -> List[?b]` で、結果に解のある `Meta` が含まれない。元の型が変更されていない
* `Subst`: `T -> List[T]` の `T` を `Int` に → `Int -> List[Int]`。別の `TypeParam` `U` は置き換わらない。`params` が空なら同じ値を返す。個数が違えば `panic`
* `Mentions`: `Func` の引数・結果、`Named` の型引数の中の `TypeParam` を見つける。解の連鎖の先の `Meta` を見つける。含まなければ偽
* `SelfType`: `type Option[T]` の `Data` → `Option[T]`（`Args[0]` が `Params[0]` と同じポインタ）。引数なしの `Data` → `Args` が `nil`

### `typecheck` の成功ケース（`TestCheckGenericSuccess`、新規）

v0.2 の `TestCheckDataSuccess` と同じ形のテーブルにする。各ケースで `mustCheck` の後に `assertComplete` を呼び、指定があれば `Info` の内容を確かめる。
`wantType` と同様に、`Info.TypeArgs` の値を `String()` で比較するヘルパー `wantTypeArgs(t, info, id, want ...string)` を追加する。

以下のソースでは、次の宣言を `P` と呼ぶ。`P` を使うケースは、ソースの先頭に `P` をそのまま連結する。

```text
type Option[T] =
    | None
    | Some(T)

type List[T] =
    | Nil
    | Cons(T, List[T])

type Pair[A, B] = Pair(A, B)

fn identity[T](x: T) -> T { x }
```

| ケース | ソース（`P` の後に続ける） | 確認すること |
| --- | --- | --- |
| identity を 2 つの型で呼ぶ | `fn main() -> Int { if identity(true) { identity(1) } else { 0 } }` | 2 つの呼び出しの型が `Bool`、`Int`。それぞれの `identity` の `TypeArgs` が `Bool`、`Int` |
| 構築子の型引数 | `fn main() -> Int { let o = Some(1) 0 }` | `Some(1)` の型が `Option[Int]`、`Some`（`Ident`）の型が `Int -> Option[Int]`、`TypeArgs` が `Int` |

| 後の使い方から決まる `None` | `fn main() -> Int { let o = None match o { Some(n) => n + 1, None => 0 } }` | `o` の `Defs` のシンボルの型が `Option[Int]`、パターン変数 `n` の型が `Int` |
| 引数の型から決まる `None` | `fn get(o: Option[Int]) -> Int { 0 }` と `fn main() -> Int { get(None) }` | `None` の `TypeArgs` が `Int` |

| 結果にだけ現れる型パラメータ | `fn none[T]() -> Option[T] { None }` と `fn main() -> Int { let o: Option[Bool] = none() 0 }` | `none` の `TypeArgs` が `Bool` |

### テストのヘルパーの変更

`typecheck_test.go` の既存のヘルパーを、多相な型に対応させる。

* `assertComplete`:
  * `info.TypeArgs` が `nil` でないことを確かめる。
  * 各型宣言で、`len(data.Params) == len(td.TypeParams)` で、名前が順に一致することを確かめる。
  * 最後に、`Info` のすべての型（`Types` の値、`Defs`・`PatVars`・`Params` のシンボルの `Type`、`FuncLits` の値、`TypeArgs` の値）に `*types.Meta` が含まれないことを確かめる。
    型の中をたどって `*types.Meta` を探す、テスト用のヘルパー `containsMeta(t types.Type) bool` を追加する。
* `walkExpr` の `*ast.Ident`:
  * シンボルが `TypeParams` を持つとき、`info.TypeArgs[e]` があり、その個数が `len(sym.TypeParams)` と一致することを確かめ、`types.Subst(sym.Type, sym.TypeParams, info.TypeArgs[e])` を式の型と `types.Equal` で比べる。
  * `TypeParams` を持たないとき、`info.TypeArgs[e]` がないことを確かめ、v0.2 と同じく `sym.Type` と比べる。
  * `TypeArgs` を持つ `Ident` の数を数え、最後に `len(info.TypeArgs)` と一致することを確かめる（`walkExpr` の引数に数を足す）。
* `walkPattern` の `*ast.CtorPat`:
  * `want` が `nil` でなければ `*types.Named` で、その `Data` が `ctor.Data` と同じポインタであることを確かめる。
  * 引数のパターンに渡す型を `types.Subst(ctor.Fields[i], ctor.Data.Params, want.(*types.Named).Args)` にする。
